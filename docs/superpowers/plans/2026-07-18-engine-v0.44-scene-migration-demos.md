# Engine v0.44 — Migrate rendering demos onto Scene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate csm_demo, normalmap_demo, and parallax_light_demo off their manual `PerspectiveCamera`/`MeshRenderer`/`setPointLights` paths onto `Scene`/ECS (`CameraComponent` + `MeshComponent` + `LightComponent`), adding a reusable `lookAtTransform` camera-conversion helper and establishing the animated-`LightComponent` pattern.

**Architecture:** A raw `lookAt` camera becomes a `CameraComponent` entity whose `TransformComponent` is built by a new `lookAtTransform` helper (exact reproduction of `glm::lookAt`, unit-tested). Geometry becomes `MeshComponent` entities (materials attached lazily once a `Renderer` exists). Static lights become `LightComponent` entities; animated lights are entities whose `TransformComponent.translation` is mutated per frame in `onRender`. Each game calls `m_scene.render(renderer, aspect)`; SDF text stays a `renderer.drawText` overlay. `Scene::render` wiring is unchanged (stays additive).

**Tech Stack:** C++17, OpenGL 4.6 deferred renderer, EnTT, GLM, Catch2 (`bot_arena_tests`), CMake.

```cpp
// A TransformComponent whose viewMatrix() equals glm::lookAt(eye, target, up).
// world = inverse(lookAt) = translate(eye) * rotate; we extract eye as the
// translation and the rotation as a quaternion. Reproduces a raw lookAt camera
// exactly (the quat_cast round-trip is sub-pixel), so a migrated Scene camera
// matches the original view matrix.
inline TransformComponent lookAtTransform(
    const glm::vec3& eye, const glm::vec3& target,
    const glm::vec3& up = glm::vec3(0.0f, 1.0f, 0.0f)) {
  const glm::mat4 world = glm::inverse(glm::lookAt(eye, target, up));
  TransformComponent t;
  t.translation = eye;
  t.rotation = glm::quat_cast(glm::mat3(world));
  return t;
}
```

(No new includes: `SceneCamera.hpp` already includes `<glm/glm.hpp>`, `<glm/gtc/matrix_transform.hpp>`, `<glm/gtc/quaternion.hpp>`, and `Components.hpp`.)

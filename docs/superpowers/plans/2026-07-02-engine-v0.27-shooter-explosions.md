# Engine v0.27 Shooter Explosions on Kills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spawn particle explosions when ships die in `shooter_game` — a tier-scaled burst at each enemy kill (bullet or ram) and a bigger blast on player death.

**Architecture:** Add one `engine::ParticleSystem` to `ShooterGame`, emit an `EmitParams` burst at each death, update it in `stepSim`, and submit its particles as additive HDR billboards in `onRender`. Reuses the v0.20 particle system verbatim.

**Tech Stack:** C++20, EnTT, glm, the engine particle system, CMake.

## Global Constraints

- C++20, 2-space indent, Google clang-format (pre-commit hook). No AI attribution. Conventional Commits, subject ≤72 chars, imperative, capitalized, no trailing period.
- Reuse `engine::ParticleSystem` (`engine/particles/ParticleSystem.hpp`): `emit(const EmitParams&, const glm::vec3& origin, std::mt19937&)`, `update(float dt)`, `particles()` → `const std::vector<engine::Particle>&`. `engine::EmitParams`/`engine::Particle`/`engine::renderColor(const Particle&)` come from the same header. `engine::ParticleInstance` (`engine/renderer/ParticleInstance.hpp`) is `{glm::vec3 position; float size; glm::vec4 color;}`. Draw with `renderer.submitParticles(const std::vector<engine::ParticleInstance>&)`.
- Reuse `ShooterGame`'s existing `std::mt19937 m_rng`. New member: `engine::ParticleSystem m_explosions;`.
- Presets are local free functions in an anonymous namespace in `ShooterGame.cpp` (particles_game presets are not exported): `engine::EmitParams enemyExplosion(int tier)` and `engine::EmitParams playerExplosion()` with the exact bodies below.
- Emit points in `stepSim`: enemy killed (health `<= 0`) → `enemyExplosion(tier)` at the enemy position; enemy ram → `enemyExplosion(tier)` at the enemy position; player death (HP `<= 0`) → `playerExplosion()` at the player position before recentring. `m_explosions.update(dt)` at the end of `stepSim`.
- `shooter_game` only; `bot_arena`/`arena_game`/`particles_game`/`models_game` untouched. No new unit test (integration on the already-tested particle system).
- Build: `cmake --build build --target shooter_game`. Tests: `ctest --test-dir build`. Screenshot: `cd build && BOTARENA_SCREENSHOT=<path> ./shooter_game`.

```cpp
namespace {

engine::EmitParams enemyExplosion(int tier) {
  engine::EmitParams p;
  p.count = 24 + tier * 18;  // 24 / 42 / 60
  p.speedMin = 2.0f;
  p.speedMax = 4.0f + tier * 1.5f;
  p.direction = {0.0f, 0.0f, 0.0f};  // radial
  p.spread = 1.0f;
  p.color = {1.0f, 0.5f, 0.15f};  // warm orange
  p.sizeMin = 0.12f;
  p.sizeMax = 0.22f + tier * 0.08f;
  p.lifeMin = 0.4f;
  p.lifeMax = 0.9f;
  p.gravity = {0.0f, -6.0f, 0.0f};
  return p;
}

}  // namespace
```

- [ ] **Step 3: Emit at enemy death (bullet kill + ram) in `stepSim`**

position and emit before pushing the enemy to `killed`:

```cpp

          const int tier = m_registry.get<Enemy>(en).tier;
```

In the ram loop (enemies overlapping the player), emit at the enemy position:


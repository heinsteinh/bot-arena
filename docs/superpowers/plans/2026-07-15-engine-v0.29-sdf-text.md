# Engine v0.29 — SDF Text (Slice 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a single-channel SDF text backend (FreeType `FT_RENDER_MODE_SDF`, zero new dependencies) so text stays crisp at any scale, selected by the font's `backend` tag; the bitmap path and all shipped callers are unchanged.

**Architecture:** A new `SdfFreeTypeSource` bakes an R8 signed-distance atlas (reusing `ShelfPacker` and the unchanged `BakedFont`) and sets `pxRange`. The OpenGL backend gains a second `sdf` shader program sharing the existing text VAO/vertex format; `drawTextBatch` becomes backend-aware and picks the program per batch. `TextRenderer::Batch` carries `pxRange`; `Renderer` registers the SDF source and forwards `backend`+`pxRange` to the backend. Only `text_demo` opts into SDF this slice.

**Tech Stack:** C++17/20, OpenGL 4.6 (DSA), FreeType (already vendored), GLM, Catch2, CMake, spdlog.

## Global Constraints

- **Behavior-preserving for shipped callers:** debug HUD, `shooter_game`, `arena_game` stay on the bitmap backend and render identically. Only `text_demo` uses SDF.
- **No new dependencies.** FreeType only; `msdfgen`/`msdf-atlas-gen` are NOT added.
- **Atlas stays R8.** SDF is single-channel; `BakedFont`/`GlyphAtlas`/the atlas factory are unchanged. (R8 textures already sample `GL_LINEAR` — no filtering change needed.)
- **SDF spread = 8 px** (FreeType `sdf` module `spread` property); `pxRange` is stored from it.
- **GL/FreeType confined to engine TUs.** New unit-tested code stays free of GL/FreeType/SDL; `SdfFreeTypeSource.cpp` (FreeType) is engine-only, NOT added to `bot_arena_tests`.
- **Every task keeps the full build green** (`cmake --build build` all targets) — changes add alongside; the one signature change (`drawTextBatch`) updates its single call site in the same task.
- **Commit hygiene:** the repo has ~22 UNTRACKED asset files under `assets/` that must STAY untracked. Never `git add -A`/`git add .`/`git add assets`; stage only the files each task lists, by explicit path; verify `git show --stat HEAD` before reporting DONE.

- [ ] **Step 2: Create `engine/renderer/text/SdfFreeTypeSource.cpp`**

```cpp
#include "engine/renderer/text/SdfFreeTypeSource.hpp"

#include <ft2build.h>
#include <spdlog/spdlog.h>

#include <vector>

#include "engine/renderer/text/ShelfPacker.hpp"
#include FT_FREETYPE_H
#include FT_MODULE_H  // FT_Property_Set

namespace engine {

bool SdfFreeTypeSource::bake(const FontDesc& desc, BakedFont& out) {
  FT_Library ft;
  if (FT_Init_FreeType(&ft)) {
    spdlog::error("FreeType init failed");
    return false;
  }
  // Distance range (px) baked around each edge; 0.5 sample == glyph edge.
  const FT_Int spread = 8;
  FT_Property_Set(ft, "sdf", "spread", &spread);

  FT_Face face;
  if (FT_New_Face(ft, desc.family.c_str(), 0, &face)) {
    spdlog::error("Failed to load font: {}", desc.family);
    FT_Done_FreeType(ft);
    return false;
  }
  FT_Set_Pixel_Sizes(face, 0, desc.pixelSize);

  const int atlasW = 512;
  ShelfPacker packer(atlasW, /*pad=*/1);

  struct Pending {
    char32_t cp;
    int x, y, w, h, bx, by;
    float adv;
    std::vector<unsigned char> bmp;
  };
  std::vector<Pending> pend;
  for (char32_t c = desc.glyphRange.first; c <= desc.glyphRange.last; ++c) {
    if (FT_Load_Char(face, c, FT_LOAD_DEFAULT)) continue;  // load outline
    FT_GlyphSlot g = face->glyph;
    // Render an SDF only when there is an outline; blanks (space) keep advance.
    if (g->format == FT_GLYPH_FORMAT_OUTLINE && g->outline.n_points > 0) {
      if (FT_Render_Glyph(g, FT_RENDER_MODE_SDF)) {
        // Render failed for this glyph: treat as a blank, keep advance only.
        g->bitmap.width = 0;
        g->bitmap.rows = 0;
      }
    }
    const int w = static_cast<int>(g->bitmap.width);
    const int h = static_cast<int>(g->bitmap.rows);
    const glm::ivec2 at = packer.place(w, h);
    Pending p;
    p.cp = c;
    p.x = at.x;
    p.y = at.y;
    p.w = w;
    p.h = h;
    p.bx = g->bitmap_left;  // adjusted by FreeType for the SDF spread padding
    p.by = g->bitmap_top;
    p.adv = static_cast<float>(g->advance.x >> 6);
    if (w > 0 && h > 0) {
      p.bmp.assign(g->bitmap.buffer, g->bitmap.buffer + (w * h));
    }
    pend.push_back(std::move(p));
  }
  const int atlasH = packer.height();

  out.atlasWidth = atlasW;
  out.atlasHeight = atlasH;
  out.pxRange = static_cast<float>(spread);
  out.atlasPixels.assign(static_cast<size_t>(atlasW) * atlasH, 0);
  for (const Pending& p : pend) {
    for (int row = 0; row < p.h; ++row) {
      for (int col = 0; col < p.w; ++col) {
        out.atlasPixels[(p.y + row) * atlasW + (p.x + col)] =
            p.bmp[row * p.w + col];
      }
    }
    Glyph gl;
    gl.size = {static_cast<float>(p.w), static_cast<float>(p.h)};
    gl.bearing = {static_cast<float>(p.bx), static_cast<float>(p.by)};
    gl.advance = p.adv;
    gl.uvMin = {static_cast<float>(p.x) / atlasW,
                static_cast<float>(p.y) / atlasH};
    gl.uvMax = {static_cast<float>(p.x + p.w) / atlasW,
                static_cast<float>(p.y + p.h) / atlasH};
    out.glyphs[p.cp] = gl;
  }

  out.metrics.pixelSize = static_cast<float>(desc.pixelSize);
  out.metrics.ascent = static_cast<float>(face->size->metrics.ascender >> 6);
  out.metrics.descent = static_cast<float>(face->size->metrics.descender >> 6);
  out.metrics.lineGap = static_cast<float>(face->size->metrics.height >> 6);

  FT_Done_Face(face);
  FT_Done_FreeType(ft);
  return true;
}

}  // namespace engine
```

- [ ] **Step 3: Compile the `sdf` program in the text init block (`OpenGLBackend.cpp`)**

The text-overlay init block builds `m_textProgram` from a vertex shader `vs` and fragment shader `fs`, then sets up `m_textVao`/`m_textVbo`. Immediately AFTER the `glDeleteShader(v); glDeleteShader(f);` that follows `m_textProgram` linking (and BEFORE the `glCreateVertexArrays(1, &m_textVao);` line), insert a second program that reuses the same vertex shader source `vs` with an SDF fragment shader:

```cpp
    // SDF text: resolve coverage from the distance field; crisp at any scale.
    constexpr const char* sdfFs = R"(
      #version 460 core
      in vec2 vUV;
      in vec4 vFill;
      out vec4 FragColor;
      uniform sampler2D uAtlas;
      uniform float uPxRange;  // reserved for effects; AA uses fwidth here
      void main() {
        float d = texture(uAtlas, vUV).r;      // 0.5 == glyph edge
        float w = fwidth(d);
        float a = smoothstep(0.5 - w, 0.5 + w, d);
        FragColor = vec4(vFill.rgb, vFill.a * a);
      }
    )";
    const unsigned int sv = compileShader(GL_VERTEX_SHADER, vs);
    const unsigned int sf = compileShader(GL_FRAGMENT_SHADER, sdfFs);
    m_sdfTextProgram = glCreateProgram();
    glAttachShader(m_sdfTextProgram, sv);
    glAttachShader(m_sdfTextProgram, sf);
    glLinkProgram(m_sdfTextProgram);
    glDeleteShader(sv);
    glDeleteShader(sf);
```

(The `vs` source string is still in scope inside the init block; reusing it keeps the two programs' vertex stage identical. The `m_textVao`/`m_textVbo` created just below are shared by both programs.)

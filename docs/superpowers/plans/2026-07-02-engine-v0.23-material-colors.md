# Engine v0.23 Model Material Colors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read each sub-mesh's diffuse color from the `.mtl` via Assimp and render multi-material models with real per-part colors (no UV/shader/texture change).

**Architecture:** `loadModel` stops merging sub-meshes: it builds one position+normal mesh per `aiMesh`, reads that mesh's Assimp diffuse color into an engine `Material`, and returns a list of `{mesh, material}` sub-meshes. The viewer submits every sub-mesh with its material under the model transform, and gains a committed multi-color demo model (`monitor.obj`).

**Tech Stack:** C++20, Assimp, OpenGL, glm, ImGui, CMake.

## Global Constraints

- C++20, 2-space indent, Google clang-format (pre-commit hook). No AI attribution. Conventional Commits, subject ≤72 chars, imperative, capitalized, no trailing period.
- `engine/assets/ModelLoader.hpp`: `struct Submesh { MeshHandle mesh = 0; MaterialHandle material = 0; };` `struct Model { std::vector<Submesh> submeshes; AABB bounds{}; bool valid = false; };` `Model loadModel(const std::string& path, ResourceRegistry& registry, ShaderHandle shader);`
- Per `aiMesh`: position+normal `VertexArray` → `registerMesh`; diffuse color via `aiGetMaterialColor(mat, AI_MATKEY_COLOR_DIFFUSE, &c)` (fallback `glm::vec4(0.8f, 0.8f, 0.8f, 1.0f)` when absent or no material) → `registerMaterial({color, 0.0f, 0.55f, shader})`; push `{mesh, material}`. Bounds via `computeBounds` over all positions across sub-meshes. Failure / no geometry → `{valid=false}`.
- `Material{ glm::vec4 baseColor; float metallic; float roughness; ShaderHandle shader; }`; handles are `uint16_t`.
- Viewer: `loadModel(assetPath(e.path), renderer.registry(), renderer.meshShader())`; render the selected model by submitting **every** sub-mesh with its material under `fitToUnitTransform(bounds) * rotate(angle)`. Commit `monitor.obj`/`monitor.mtl`; add "Monitor" as the default (first) entry.
- No vertex-layout / `mesh.glsl` / texture changes. `bot_arena`/`arena_game`/`particles_game` untouched.
- Build: `cmake --build build`. Tests: `ctest --test-dir build --output-on-failure`. Screenshot: `cd build && BOTARENA_SCREENSHOT=<path> ./models_game`.

- [ ] **Step 2: Rewrite `engine/assets/ModelLoader.cpp`**

```cpp
#include "engine/assets/ModelLoader.hpp"

#include <spdlog/spdlog.h>

#include <cstdint>
#include <vector>

#include <assimp/material.h>
#include <assimp/postprocess.h>
#include <assimp/scene.h>

#include <assimp/Importer.hpp>

#include "engine/renderer/Buffer.hpp"
#include "engine/renderer/VertexArray.hpp"

namespace engine {

namespace {
glm::vec4 diffuseColor(const aiScene* scene, const aiMesh* mesh) {
  glm::vec4 color(0.8f, 0.8f, 0.8f, 1.0f);
  if (mesh->mMaterialIndex < scene->mNumMaterials) {
    const aiMaterial* mat = scene->mMaterials[mesh->mMaterialIndex];
    aiColor4D c;
    if (aiGetMaterialColor(mat, AI_MATKEY_COLOR_DIFFUSE, &c) == AI_SUCCESS) {
      color = {c.r, c.g, c.b, 1.0f};
    }
  }
  return color;
}

MeshHandle buildMesh(const aiMesh* mesh, ResourceRegistry& registry) {
  std::vector<float> verts;  // interleaved px,py,pz,nx,ny,nz
  verts.reserve(mesh->mNumVertices * 6);
  for (unsigned i = 0; i < mesh->mNumVertices; ++i) {
    const aiVector3D& p = mesh->mVertices[i];
    const aiVector3D n =
        mesh->mNormals ? mesh->mNormals[i] : aiVector3D(0.0f, 1.0f, 0.0f);
    verts.insert(verts.end(), {p.x, p.y, p.z, n.x, n.y, n.z});
  }
  std::vector<uint32_t> indices;
  for (unsigned f = 0; f < mesh->mNumFaces; ++f) {
    const aiFace& face = mesh->mFaces[f];
    for (unsigned j = 0; j < face.mNumIndices; ++j) {
      indices.push_back(face.mIndices[j]);
    }
  }

  auto va = VertexArray::Create();
  auto vb = VertexBuffer::Create(
      verts.data(), static_cast<uint32_t>(verts.size() * sizeof(float)));
  vb->setLayout({
      {ShaderDataType::Float3, "a_position"},
      {ShaderDataType::Float3, "a_normal"},
  });
  va->addVertexBuffer(vb);
  va->setIndexBuffer(IndexBuffer::Create(
      indices.data(), static_cast<uint32_t>(indices.size())));
  return registry.registerMesh(va);
}
}  // namespace

Model loadModel(const std::string& path, ResourceRegistry& registry,
                ShaderHandle shader) {
  Assimp::Importer importer;
  const aiScene* scene = importer.ReadFile(
      path, aiProcess_Triangulate | aiProcess_GenSmoothNormals |
                aiProcess_JoinIdenticalVertices |
                aiProcess_PreTransformVertices);
  if (!scene || (scene->mFlags & AI_SCENE_FLAGS_INCOMPLETE) ||
      !scene->mRootNode) {
    spdlog::error("Failed to load model {}: {}", path,
                  importer.GetErrorString());
    return Model{};
  }

  Model model;
  std::vector<glm::vec3> positions;
  uint32_t totalTris = 0;
  for (unsigned m = 0; m < scene->mNumMeshes; ++m) {
    const aiMesh* mesh = scene->mMeshes[m];
    if (mesh->mNumVertices == 0 || mesh->mNumFaces == 0) continue;
    for (unsigned i = 0; i < mesh->mNumVertices; ++i) {
      const aiVector3D& p = mesh->mVertices[i];
      positions.push_back({p.x, p.y, p.z});
    }
    const MeshHandle meshHandle = buildMesh(mesh, registry);
    const MaterialHandle mat = registry.registerMaterial(
        {diffuseColor(scene, mesh), 0.0f, 0.55f, shader});
    model.submeshes.push_back({meshHandle, mat});
    totalTris += mesh->mNumFaces;
  }

  if (model.submeshes.empty()) {
    spdlog::error("Model {} has no geometry", path);
    return Model{};
  }

  model.bounds = computeBounds(positions.data(), positions.size());
  model.valid = true;
  spdlog::info("Loaded model {} ({} submeshes, {} tris)", path,
               model.submeshes.size(), totalTris);
  return model;
}

}  // namespace engine
```

# Engine v0.26 Shooter Player Health & Enemy Fire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two-way combat in `shooter_game` — the player has health and 3 lives; enemies face the player and fire back; bullets have factions (green player / red enemy) and point along their travel; death respawns, 0 lives resets.

**Architecture:** Extends `ShooterGame`'s ECS sim with a `Health` component, bullet factions, and enemy fire. Enemies aim at the player and shoot; enemy bullets damage the player via the v0.19 `adjustHealth`; bullets render with a per-faction override material rotated along their velocity.

**Tech Stack:** C++20, EnTT, glm, Assimp models, text HUD, CMake.

## Global Constraints

- C++20, 2-space indent, Google clang-format (pre-commit hook). No AI attribution. Conventional Commits, subject ≤72 chars, imperative, capitalized, no trailing period.
- `games/shooter/Components.hpp`: `Health{float current; float max;}`; `Bullet{float life; bool fromPlayer = true;}`; `Enemy{int tier; float fireTimer = 0.0f;}`. Player entity gets `Health{100, 100}`.
- Factions: player bullets `fromPlayer = true` (green, hit enemies); enemy bullets `fromPlayer = false` (red, hit the player). Bullet `yaw = engine::headingToYaw(velocity)` at spawn.
- Enemies face the player: `yaw = engine::headingToYaw(playerPos - enemyPos)`. Each `Enemy.fireTimer` counts down; when `< kFireRange` of the player, fire toward the player at `kEnemyBulletSpeed` and reset to `kEnemyFireCooldown`. Do NOT create entities while iterating a view — collect fire origins, spawn after the loop.
- Damage via `engine::adjustHealth(current, delta, max)` (`engine/gameplay/Combat.hpp`): enemy bullet `-kEnemyBulletDamage` (10); enemy ram (overlap) `-kRamDamage` (25) + enemy destroyed. HP ≤ 0 → `m_lives--`; if `> 0` respawn (reset HP, recentre, destroy enemy bullets); else reset (destroy all enemies + bullets, `m_score = 0`, `m_lives = kLives`, HP full, recentre).
- Rendering: register `m_playerBulletMat` (green) + `m_enemyBulletMat` (red); bullets draw the Projectile model with the faction material at `yaw + kBulletYawOffset`. HUD (v0.17 text): `Score` / `HP: cur/max` / `Lives` / `Enemies`.
- Reuse `engine::headingToYaw`/`forwardFromYaw`/`circlesOverlapXZ` (v0.25), `engine::adjustHealth` (v0.19), `MeshRenderer`, `Font`/`drawText`. `bot_arena`/`arena_game`/`particles_game`/`models_game` untouched.
- Build: `cmake --build build`. Tests: `ctest --test-dir build --output-on-failure`. Screenshot: `cd build && BOTARENA_SCREENSHOT=<path> ./shooter_game`.

Then, after the bullet→enemy hit block, add enemy-bullet damage:

```cpp
  // Enemy bullets damage the player.
  std::vector<entt::entity> spent;
  for (const entt::entity b : m_registry.view<Transform, Bullet>()) {
    if (m_registry.get<Bullet>(b).fromPlayer) continue;
    const glm::vec3& bp = m_registry.get<Transform>(b).position;
    if (engine::circlesOverlapXZ(bp, kBulletRadius, playerPos, kPlayerRadius)) {
      ph.current = engine::adjustHealth(ph.current, -kEnemyBulletDamage, ph.max);
      spent.push_back(b);
    }
  }
  for (const entt::entity e : spent) m_registry.destroy(e);

  // Enemies ramming the player deal heavy damage and are destroyed.
  std::vector<entt::entity> rammed;
  for (const entt::entity en : m_registry.view<Transform, Enemy>()) {
    const glm::vec3& ep = m_registry.get<Transform>(en).position;
    if (engine::circlesOverlapXZ(ep, kEnemyRadius, playerPos, kPlayerRadius)) {
      ph.current = engine::adjustHealth(ph.current, -kRamDamage, ph.max);
      rammed.push_back(en);
    }
  }
  for (const entt::entity e : rammed) m_registry.destroy(e);

  // Death: lose a life and respawn; out of lives resets the run.
  if (ph.current <= 0.0f) {
    --m_lives;
    m_registry.get<Transform>(playerEnt).position = {0.0f, 0.4f, 0.0f};
    ph.current = ph.max;
    if (m_lives > 0) {
      std::vector<entt::entity> clearBullets;
      for (const entt::entity b : m_registry.view<Bullet>()) {
        if (!m_registry.get<Bullet>(b).fromPlayer) clearBullets.push_back(b);
      }
      for (const entt::entity e : clearBullets) m_registry.destroy(e);
    } else {
      std::vector<entt::entity> wipe;
      for (const entt::entity e : m_registry.view<Enemy>()) wipe.push_back(e);
      for (const entt::entity e : m_registry.view<Bullet>()) wipe.push_back(e);
      for (const entt::entity e : wipe) m_registry.destroy(e);
      m_score = 0;
      m_lives = kLives;
    }
  }
```

Remove the old `breached`/`m_leaks` block entirely.

# Engine v0.19 Health & Combat Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add contact-based combat to the arena — Health on player and bots, mutual contact damage, bot death/recycle and player respawn, bot regen, low-health flee, and an on-screen HP/Kills readout.

**Architecture:** A pure `engine/gameplay/Combat.hpp` (`adjustHealth`, `shouldFlee`) holds the health math. `ArenaGame` gains a `Health` component, a health-aware steering branch (flee when low), a combat pass (contact damage + regen), and a death/respawn pass, plus a text readout via the v0.17 renderer.

**Tech Stack:** C++20, EnTT, glm, Catch2, FreeType text (v0.17), CMake.

## Global Constraints

- C++20, 2-space indent, Google clang-format (pre-commit hook). No AI attribution. Conventional Commits, subject ≤72 chars, imperative, capitalized, no trailing period.
- `engine/gameplay/Combat.hpp` (header-only, EnTT/GL-free): `float adjustHealth(float current, float delta, float max)` (clamp `current+delta` to `[0,max]`), `bool shouldFlee(float current, float max, float fleeFraction)` (`current > 0 && current <= max*fleeFraction`).
- `Health { float current = 0.0f; float max = 0.0f; }` in `games/arena/Components.hpp`. Player `Health{100,100}`; bots `Health{30,30}`.
- Constants in `ArenaGame`: `kPlayerMaxHealth = 100.0f`, `kBotMaxHealth = 30.0f`, `kPlayerDps = 40.0f`, `kBotDps = 8.0f`, `kBotRegen = 6.0f`, `kFleeFraction = 0.35f`, `kArenaEdge = 4.5f`. Members: `int m_kills = 0`, `int m_deaths = 0`, `engine::Ref<engine::Font> m_font`.
- `stepSim` order: input → **health-aware steering (flee if `shouldFlee` else seek)** → integrate → agent collision → wall bounce → **combat (contact mutual DPS; else bot regen)** → **death/respawn (bot recycle to edge ring + `m_kills++`; player recenter + `m_deaths++`)**. Steps 3–5 unchanged from v0.16.
- Contact test: XZ distance `< botScale + playerScale`. Recycle position: `(cos(a)*kArenaEdge, 0.3, sin(a)*kArenaEdge)` for a uniform random angle `a`.
- Readout: `ArenaGame::onRender` draws `HP: <cur> / <max>` and `Kills: <m_kills>` bottom-left, scale `0.7`, white, via `renderer.drawText`. Font loaded in `onAttach` via `engine::Font::Load(std::string(BOTARENA_ASSET_DIR) + "/fonts/DejaVuSans.ttf", 32)`.
- No engine-renderer, `bot_arena`, or `BotArenaGame` changes.
- Build: `cmake --build build`. Tests: `ctest --test-dir build --output-on-failure`. Screenshot: `cd build && BOTARENA_SCREENSHOT=<path> ./arena_game`.

```cpp
#ifndef ENGINE_GAMEPLAY_COMBAT_HPP
#define ENGINE_GAMEPLAY_COMBAT_HPP

namespace engine {

// Clamp current+delta to [0, max]. delta<0 damages, delta>0 heals.
inline float adjustHealth(float current, float delta, float max) {
  const float v = current + delta;
  if (v < 0.0f) return 0.0f;
  if (v > max) return max;
  return v;
}

// True when the agent is alive and at/under the flee fraction of max health.
inline bool shouldFlee(float current, float max, float fleeFraction) {
  return current > 0.0f && current <= max * fleeFraction;
}

}  // namespace engine

#endif  // ENGINE_GAMEPLAY_COMBAT_HPP
```

- [ ] **Step 2: Make bot steering health-aware**

In `stepSim`, replace the existing bot-steering loop body (the `view<Transform,
Velocity, Bot>` loop that calls `engine::seek`) with a health-aware branch:

```cpp
  for (const entt::entity e : m_registry.view<Transform, Velocity, Bot>()) {
    Transform& tr = m_registry.get<Transform>(e);
    Velocity& v = m_registry.get<Velocity>(e);
    const Health& h = m_registry.get<Health>(e);
    const glm::vec3 force =
        engine::shouldFlee(h.current, h.max, kFleeFraction)
            ? engine::flee(tr.position, v.value, playerPos, kBotMaxSpeed,
                           kBotMaxForce)
            : engine::seek(tr.position, v.value, playerPos, kBotMaxSpeed,
                           kBotMaxForce);
    v.value += force * dt;
    v.value = engine::truncate(v.value, kBotMaxSpeed);
  }
```

- [ ] **Step 3: Add the combat + death/respawn passes at the end of `stepSim`**

After the wall-bounce loop (the last loop in `stepSim`), before the closing `}`:

```cpp
  // Combat: contact damage between the player and touching bots; bots regen
  // while not in contact.
  entt::entity playerEnt = entt::null;
  for (const entt::entity e : m_registry.view<Transform, Player>()) {
    playerEnt = e;
  }
  if (playerEnt != entt::null) {
    Transform& pt = m_registry.get<Transform>(playerEnt);
    Health& ph = m_registry.get<Health>(playerEnt);
    for (const entt::entity e : m_registry.view<Transform, Health, Bot>()) {
      Transform& bt = m_registry.get<Transform>(e);
      Health& bh = m_registry.get<Health>(e);
      const float dx = bt.position.x - pt.position.x;
      const float dz = bt.position.z - pt.position.z;
      const float dist = std::sqrt(dx * dx + dz * dz);
      if (dist < bt.scale + pt.scale) {
        ph.current = engine::adjustHealth(ph.current, -kBotDps * dt, ph.max);
        bh.current = engine::adjustHealth(bh.current, -kPlayerDps * dt, bh.max);
      } else {
        bh.current = engine::adjustHealth(bh.current, kBotRegen * dt, bh.max);
      }
    }

    // Death / respawn.
    std::uniform_real_distribution<float> angleD(0.0f, 6.2831853f);
    for (const entt::entity e : m_registry.view<Transform, Health, Bot>()) {
      Health& bh = m_registry.get<Health>(e);
      if (bh.current <= 0.0f) {
        Transform& bt = m_registry.get<Transform>(e);
        const float a = angleD(m_rng);
        bt.position = {std::cos(a) * kArenaEdge, 0.3f, std::sin(a) * kArenaEdge};
        bh.current = bh.max;
        ++m_kills;
      }
    }
    if (ph.current <= 0.0f) {
      pt.position = {0.0f, 0.3f, 0.0f};
      ph.current = ph.max;
      ++m_deaths;
    }
  }
```

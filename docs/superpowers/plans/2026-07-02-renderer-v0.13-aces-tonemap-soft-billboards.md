# Renderer v0.13 ACES Tonemap & Soft Billboards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Reinhard with ACES filmic tonemapping + a manual exposure in the composite, and make the emissive light billboards soft-particle depth-occluded via the G-buffer world-position.

**Architecture:** Two shader-level changes on the existing deferred/HDR pipeline. The composite (`compositeBloom`) applies an exposure multiply + the Narkowicz ACES curve instead of Reinhard. The emissive billboard shader samples the G-buffer world-position (RT2) to fade/occlude each orb against scene geometry (soft particles), with no depth-buffer sharing.

**Tech Stack:** C++20, OpenGL 4.6 core (DSA) via GLAD, glm, spdlog, Catch2, CMake + vcpkg.

**Files:**

**Interfaces:**

- [ ] **Step 1: Replace the composite fragment shader body**

In `createCompositeProgram` in `engine/renderer/opengl/OpenGLBackend.cpp`, replace
the `fs` raw string with the ACES version:

```cpp
  constexpr const char* fs = R"(
    #version 460 core
    in vec2 v_uv;
    out vec4 fragColor;
    uniform sampler2D u_scene;
    uniform sampler2D u_bloom;
    uniform float u_bloomIntensity;
    uniform float u_exposure;
    vec3 aces(vec3 x) {
      const float a = 2.51, b = 0.03, c = 2.43, d = 0.59, e = 0.14;
      return clamp((x * (a * x + b)) / (x * (c * x + d) + e), 0.0, 1.0);
    }
    void main() {
      vec3 hdr = (texture(u_scene, v_uv).rgb +
                  texture(u_bloom, v_uv).rgb * u_bloomIntensity) * u_exposure;
      vec3 c = aces(hdr);
      c = pow(c, vec3(1.0 / 2.2));   // gamma
      fragColor = vec4(c, 1.0);
    }
  )";
```

- [ ] **Step 1: Emit world position from the emissive vertex shader**

In `createEmissiveProgram` in `engine/renderer/opengl/OpenGLBackend.cpp`, add the
`v_worldPos` output and set it. Change the vertex `out`s + body:

```cpp
    uniform float u_size;
    out vec2 v_local;
    out vec3 v_color;
    out vec3 v_worldPos;
    void main() {
      vec3 center = u_points[gl_InstanceID].positionRadius.xyz;
      v_color =
          u_points[gl_InstanceID].color.rgb * u_points[gl_InstanceID].color.a;
      vec3 right = vec3(u_view[0][0], u_view[1][0], u_view[2][0]);
      vec3 up = vec3(u_view[0][1], u_view[1][1], u_view[2][1]);
      v_local = a_position * 2.0 - 1.0;
      vec3 world = center + (v_local.x * right + v_local.y * up) * u_size;
      v_worldPos = world;
      gl_Position = u_viewProjection * vec4(world, 1.0);
    }
```

- [ ] **Step 2: Soft-particle fade in the emissive fragment shader**

Replace the emissive `fs` raw string with the soft-particle version (adds the
Camera UBO for `u_cameraPos`, the world-pos sampler, and the fade):

```cpp
  constexpr const char* fs = R"(
    #version 460 core
    in vec2 v_local;
    in vec3 v_color;
    in vec3 v_worldPos;
    out vec4 fragColor;
    layout(std140, binding = 0) uniform Camera {
      mat4 u_view;
      mat4 u_projection;
      mat4 u_viewProjection;
      vec4 u_cameraPos;
      mat4 u_invViewProjection;
    };
    uniform sampler2D u_gWorldPos;
    void main() {
      float falloff = smoothstep(1.0, 0.0, length(v_local));
      vec4 sceneWP = texelFetch(u_gWorldPos, ivec2(gl_FragCoord.xy), 0);
      float fade = 1.0;
      if (sceneWP.w > 0.5) {   // geometry present (sky has w == 0)
        float sceneDist = length(sceneWP.xyz - u_cameraPos.xyz);
        float fragDist = length(v_worldPos - u_cameraPos.xyz);
        fade = smoothstep(0.0, 0.5, sceneDist - fragDist);
      }
      fragColor = vec4(v_color * falloff * fade, 1.0);
    }
  )";
```

- [ ] **Step 4: Bind the world-pos texture in `drawLightBillboards`**

Replace `OpenGLBackend::drawLightBillboards` with:

```cpp
void OpenGLBackend::drawLightBillboards(int count, uint32_t gWorldPos) {
  if (count <= 0) return;
  glDisable(GL_DEPTH_TEST);
  glEnable(GL_BLEND);
  glBlendFunc(GL_ONE, GL_ONE);  // additive
  glUseProgram(m_emissiveShader);
  glUniform1f(glGetUniformLocation(m_emissiveShader, "u_size"), 0.25f);
  glBindTextureUnit(0, gWorldPos);
  glUniform1i(glGetUniformLocation(m_emissiveShader, "u_gWorldPos"), 0);
  glBindVertexArray(m_quadVao);
  glDrawArraysInstanced(GL_TRIANGLE_STRIP, 0, 4, count);
  glBindVertexArray(0);
  glDisable(GL_BLEND);
}
```

# Engine v0.36 — Point-Light Parallax Self-Shadows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend v0.35's directional parallax self-shadow to the first 3 point lights, packed into `gShadow.g/b/a`, consumed by the deferred lighting pass's point-light loop — demonstrated by a new `parallax_light_demo` with a point light orbiting low over a parallax brick floor.

**Architecture:** The geometry pass (`mesh.glsl`) already has the height map, the TBN, and (now) the PointLights UBO (binding 2, uploaded before the geometry pass). When `u_hasHeight`, after POM it marches the v0.35 `parallaxShadow` toward the directional light (→ `gShadow.r`, unchanged) and toward each of the first `min(3, u_pointCount)` point lights (→ `gShadow.g/b/a`). The lighting pass multiplies point light `i`'s contribution by `gShadow[i+1]` for `i < 3`. Non-parallax fragments write `gShadow = vec4(1.0)`.

**Tech Stack:** C++17/20, OpenGL 4.6 (deferred, DSA), GLM, CMake.

## Global Constraints

- **Backward compatible:** materials with `heightMap == null` render exactly as today — `u_hasHeight == 0` writes `gShadow = vec4(1,1,1,1)`, so every light term multiplies by 1. Existing games (arena/shooter/camera/billboard/text/normalmap) must be visually unchanged.
- **Channel convention:** `gShadow.r` = directional self-shadow (v0.35, unchanged); `gShadow.g/b/a` = point lights 0/1/2. Geometry writes `selfShadow[i+1]`; lighting reads `pShadow[i+1]` — same `i+1` convention.
- **Selection:** first `min(3, u_pointCount)` point lights by UBO index. Lights 4+ multiply by 1 (no self-shadow).
- **THE load-bearing change:** non-parallax fragments must write `gShadow = vec4(1.0)` (v0.35 wrote `(1,0,0,1)`). Without it, `.g/.b == 0` would zero point lights 0 and 1 on every non-parallax surface — the shooter/arena regression screenshots exist to catch exactly this.
- **No `lightingPass` signature change** — `gShadow` (unit 9) is already bound and sampled; this reads its other channels.
- **Every task keeps the full build + `bot_arena_tests` green.**

### Task 1: Point-light self-shadow in the shaders

Add the point-light marches to the geometry pass and the point-light attenuation to the lighting pass. Independently testable by regression (the `vec4(1.0)` default keeps existing point-lit scenes unchanged).

**Files:**
- Modify: `assets/shaders/mesh.glsl` (fragment: PointLights UBO + `vec4 selfShadow` + point marches + `gShadow` write)
- Modify: `engine/renderer/opengl/OpenGLBackend.cpp` (lighting fragment shader: `vec4 pShadow` + point-loop multiply)

**Interfaces:**
- Consumes: v0.35 `parallaxShadow(vec2 uv, vec3 lightT)`, `u_hasHeight`, the geometric `TBN`, `u_lightDir` (Light UBO), `gShadow` output.
- Produces: `gShadow` = `(dirShadow, pointShadow0, pointShadow1, pointShadow2)` for parallax fragments, `vec4(1.0)` otherwise; the lighting pass attenuates the first 3 point lights by `gShadow.g/b/a`.

- [ ] **Step 1: PointLights UBO in `mesh.glsl` fragment stage**

After the `Light` UBO block (binding 1) in the `#type fragment` section, add the PointLights block (matching the lighting shader's layout):

```glsl
struct PointLight {
    vec4 positionRadius;
    vec4 color;
};
layout(std140, binding = 2) uniform PointLights {
    int u_pointCount;
    PointLight u_points[32];
};
```

- [ ] **Step 2: March toward point lights in `mesh.glsl` `main`**

Replace this block:

```glsl
    vec2 uv = v_uv;
    float selfShadow = 1.0;
    if (u_hasHeight == 1) {
        vec3 viewT = normalize(transpose(TBN) * (u_cameraPos.xyz - v_worldPos));
        uv = parallaxOcclusion(v_uv, viewT);
        vec3 lightT = normalize(transpose(TBN) * normalize(u_lightDir.xyz));
        selfShadow = parallaxShadow(uv, lightT);
    }
```

with (self-shadow becomes a `vec4`: `.r` = directional, `.g/.b/.a` = point lights 0/1/2):

```glsl
    vec2 uv = v_uv;
    vec4 selfShadow = vec4(1.0);   // r = directional, gba = point lights 0..2
    if (u_hasHeight == 1) {
        vec3 viewT = normalize(transpose(TBN) * (u_cameraPos.xyz - v_worldPos));
        uv = parallaxOcclusion(v_uv, viewT);
        vec3 lightT = normalize(transpose(TBN) * normalize(u_lightDir.xyz));
        selfShadow.r = parallaxShadow(uv, lightT);
        int np = min(u_pointCount, 3);
        for (int i = 0; i < np; ++i) {
            vec3 Lw = normalize(u_points[i].positionRadius.xyz - v_worldPos);
            vec3 Lt = normalize(transpose(TBN) * Lw);
            selfShadow[i + 1] = parallaxShadow(uv, Lt);
        }
    }
```

- [ ] **Step 3: Write the `vec4` to `gShadow` in `mesh.glsl`**

Replace:

```glsl
    gShadow = vec4(selfShadow, 0.0, 0.0, 1.0);
```

with:

```glsl
    gShadow = selfShadow;
```

- [ ] **Step 4: Sample `gShadow` as `vec4` in the lighting shader (`OpenGLBackend.cpp`)**

In the inline lighting fragment shader, the directional block currently reads `.r` from a `float`. Replace:

```glsl
      float pShadow = texture(u_gShadow, v_uv).r;   // parallax self-shadow
      color += brdf(N, V, L, albedo, metallic, rough, F0, vec3(3.0)) *
               (1.0 - shadow) * pShadow;
```

with (sample the whole `vec4`; directional keeps using `.r`):

```glsl
      vec4 pShadow = texture(u_gShadow, v_uv);   // r=dir, gba=points 0..2
      color += brdf(N, V, L, albedo, metallic, rough, F0, vec3(3.0)) *
               (1.0 - shadow) * pShadow.r;
```

- [ ] **Step 5: Attenuate the first 3 point lights in the lighting loop (`OpenGLBackend.cpp`)**

In the point-light loop, replace:

```glsl
        vec3 radiance = u_points[i].color.rgb * u_points[i].color.a * att;
        color += brdf(N, V, Lp, albedo, metallic, rough, F0, radiance);
```

with:

```glsl
        vec3 radiance = u_points[i].color.rgb * u_points[i].color.a * att;
        float ps = i < 3 ? pShadow[i + 1] : 1.0;
        color += brdf(N, V, Lp, albedo, metallic, rough, F0, radiance) * ps;
```

- [ ] **Step 2: `ParallaxLightDemoGame.cpp`**

```cpp
#include "games/parallax_light_demo/ParallaxLightDemoGame.hpp"

#include <cmath>
#include <cstdlib>
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>
#include <string>
#include <vector>

#include "engine/assets/TextureLoader.hpp"
#include "engine/renderer/MeshRenderer.hpp"
#include "engine/renderer/PointLight.hpp"
#include "engine/renderer/Renderer.hpp"
#include "engine/renderer/text/FontDesc.hpp"
#include "engine/renderer/text/TextPlacement.hpp"
#include "engine/renderer/text/TextStyle.hpp"

namespace parallaxlightdemo {

void ParallaxLightDemoGame::onAttach() {
  m_screenshot = std::getenv("BOTARENA_SCREENSHOT") != nullptr;
  if (const char* l = std::getenv("BOTARENA_LIGHT")) m_lightPreset = std::atoi(l);
  m_camera.setPerspective(55.0f, 16.0f / 9.0f, 0.1f, 100.0f);
  m_camera.lookAt({0.5f, 5.5f, 7.0f}, {0.0f, 0.0f, -0.5f});
}

void ParallaxLightDemoGame::onUpdate(float dt) { m_time += dt; }

void ParallaxLightDemoGame::ensureResources(engine::Renderer& renderer) {
  if (m_ready) return;
  const engine::ShaderHandle s = renderer.meshShader();
  const std::string tex = std::string(BOTARENA_ASSET_DIR) + "/textures/";
  engine::Material floor;
  floor.baseColor = {1.0f, 1.0f, 1.0f, 1.0f};
  floor.roughness = 0.7f;
  floor.shader = s;
  floor.albedo = engine::loadTexture(tex + "brick_d.jpg");
  floor.normalMap = engine::loadTexture(tex + "brick_n.jpg");
  floor.heightMap = engine::loadTexture(tex + "brick_h.png");
  floor.heightScale = 0.08f;
  m_floorMat = renderer.registry().registerMaterial(floor);
  m_ready = true;
}

void ParallaxLightDemoGame::onRender(engine::Renderer& renderer, int width,
                                     int height) {
  ensureResources(renderer);
  if (!m_font) {
    engine::FontDesc desc;
    desc.family = std::string(BOTARENA_ASSET_DIR) + "/fonts/DejaVuSans.ttf";
    desc.pixelSize = 48;
    desc.backend = engine::FontBackend::SDF;
    m_font = renderer.fonts().load(desc);
  }

  const float aspect =
      height > 0 ? static_cast<float>(width) / static_cast<float>(height) : 1.0f;
  m_camera.setPerspective(55.0f, aspect, 0.1f, 100.0f);
  renderer.setCamera(m_camera);

  // One point light orbiting LOW over the floor -> sweeping mortar shadows.
  float a = m_time * 0.7f;
  if (m_screenshot) {
    a = m_lightPreset == 2 ? 3.9f : (m_lightPreset == 1 ? 2.2f : 0.4f);
  }
  std::vector<engine::PointLight> lights;
  engine::PointLight key;
  key.positionRadius = glm::vec4(std::cos(a) * 3.2f, 0.65f, std::sin(a) * 3.2f,
                                 18.0f);
  key.color = glm::vec4(1.0f, 0.88f, 0.7f, 6.0f);  // bright, warm
  lights.push_back(key);
  renderer.setPointLights(lights);
  // Directional nearly straight down -> flat fill, so the point light is the
  // unmistakable self-shadow caster.
  renderer.setLightDirection(glm::normalize(glm::vec3(0.1f, 1.0f, 0.15f)));

  const engine::MeshHandle cube = renderer.unitCubeMesh();
  engine::MeshRenderer meshes(renderer.queue(), renderer.registry(), m_camera);
  glm::mat4 floorM = glm::translate(glm::mat4(1.0f), {0.0f, -0.15f, 0.0f});
  floorM = glm::scale(floorM, {10.0f, 0.3f, 10.0f});
  meshes.submit(cube, m_floorMat, floorM);

  if (m_font) {
    engine::TextStyle st;
    st.fillColor = {1.0f, 1.0f, 1.0f, 1.0f};
    st.outlineColor = {0.05f, 0.05f, 0.08f, 1.0f};
    st.outlineWidthPx = 2.0f;
    renderer.drawText(m_font, "Point-light parallax shadows",
                      engine::TextPlacement::screen({40.0f, 60.0f}, 0.7f), st);
  }
}

}  // namespace parallaxlightdemo
```

# Engine v0.35 — Parallax Occlusion Mapping + Self-Shadowing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Parallax Occlusion Mapping to the deferred g-buffer geometry pass on the v0.34 tangent-space seam, plus correct per-light parallax self-shadowing carried through a new 4th g-buffer target and consumed by the directional light — demonstrated by a `flat | normal | normal+parallax` brick wall in `normalmap_demo`.

**Architecture:** `mesh.glsl`'s fragment stage builds the TBN from the geometric normal, ray-marches a height map in tangent space (view vector from `u_cameraPos`), and shifts `v_uv` before sampling albedo + normal. A second short ray toward the light (`u_lightDir`, already in the Light UBO) produces a soft self-shadow written to `gShadow` (g-buffer attachment 3); the deferred lighting pass multiplies only the directional light's contribution by it. Everything is gated behind `u_hasHeight`, and every geometry fragment writes `gShadow` (1.0 default) so non-parallax materials are unchanged.

**Tech Stack:** C++17/20, OpenGL 4.6 (deferred, DSA), GLM, CMake, Python+PIL (one-off asset gen).

## Global Constraints

- **Backward compatible:** materials with `heightMap == null` render exactly as today — `u_hasHeight == 0` skips POM, and `gShadow` is written `1.0` so the directional term multiplies by 1. Existing games (arena/shooter/camera/billboard/text/normalmap) must be visually unchanged.
- **Height convention:** height map is grayscale, **white = raised**; in-shader `depth = 1 - texture(...).r`.
- **Texture units in the geometry pass:** albedo 0, normal 1, **height 2**.
- **Texture unit in the lighting pass:** `gShadow` on **unit 9** (units 0–8 are in use).
- **G-buffer attachment order:** 0 albedo, 1 normal, 2 world-pos, **3 gShadow** (SSAO reads 1 & 2, emissive reads 2 — do not disturb).
- **Self-shadow caster = the directional light** (the same one driving the PCF shadow map). Point lights and IBL are never attenuated by the parallax shadow.

- [ ] **Step 3: POM in `mesh.glsl` fragment stage**

Replace the **entire `#type fragment` section** (from `#type fragment` to the end of file) with this (adds the Camera UBO for `u_cameraPos`, the height uniforms, the `parallaxOcclusion` function, and restructures `main` so the TBN is built once and the shifted `uv` feeds both albedo and normal):

```glsl
#type fragment
#version 460 core

in vec3 v_worldNormal;
in vec3 v_worldTangent;
in vec3 v_worldPos;
in vec2 v_uv;

layout(std140, binding = 0) uniform Camera {
    mat4 u_view;
    mat4 u_projection;
    mat4 u_viewProjection;
    vec4 u_cameraPos;
};

uniform vec4 u_baseColor;
uniform float u_metallic;
uniform float u_roughness;
uniform sampler2D u_albedoMap;
uniform int u_hasAlbedo;
uniform sampler2D u_normalMap;
uniform int u_hasNormal;
uniform sampler2D u_heightMap;
uniform int u_hasHeight;
uniform float u_heightScale;

layout(location = 0) out vec4 gAlbedo;
layout(location = 1) out vec4 gNormal;
layout(location = 2) out vec4 gWorldPos;

// Parallax Occlusion Mapping: steep ray-march (layers scaled by view angle)
// plus one interpolation between the last two layers. Height map: white =
// raised, so marched depth = 1 - height.
vec2 parallaxOcclusion(vec2 uv, vec3 viewT) {
    const float minLayers = 8.0;
    const float maxLayers = 32.0;
    float n = mix(maxLayers, minLayers, clamp(abs(viewT.z), 0.0, 1.0));
    float layerDepth = 1.0 / n;
    vec2 P = viewT.xy / viewT.z * u_heightScale;   // total UV shift at depth 1
    vec2 dUV = P / n;
    float curDepth = 0.0;
    vec2 curUV = uv;
    float d = 1.0 - texture(u_heightMap, curUV).r;
    while (curDepth < d) {
        curUV -= dUV;
        d = 1.0 - texture(u_heightMap, curUV).r;
        curDepth += layerDepth;
    }
    vec2 prevUV = curUV + dUV;
    float after = d - curDepth;
    float before =
        (1.0 - texture(u_heightMap, prevUV).r) - (curDepth - layerDepth);
    float w = after / (after - before);
    return mix(curUV, prevUV, w);
}

void main() {
    vec3 Ngeo = normalize(v_worldNormal);
    vec3 T = normalize(v_worldTangent - dot(v_worldTangent, Ngeo) * Ngeo);
    mat3 TBN = mat3(T, cross(Ngeo, T), Ngeo);

    vec2 uv = v_uv;
    if (u_hasHeight == 1) {
        vec3 viewT = normalize(transpose(TBN) * (u_cameraPos.xyz - v_worldPos));
        uv = parallaxOcclusion(v_uv, viewT);
    }

    vec3 albedo = u_hasAlbedo == 1
        ? texture(u_albedoMap, uv).rgb * u_baseColor.rgb
        : u_baseColor.rgb;
    gAlbedo = vec4(albedo, u_metallic);

    vec3 N = Ngeo;
    if (u_hasNormal == 1) {
        vec3 tn = texture(u_normalMap, uv).rgb * 2.0 - 1.0;
        N = normalize(TBN * tn);
    }
    gNormal = vec4(N, u_roughness);
    gWorldPos = vec4(v_worldPos, 1.0);
}
```

Add the self-shadow function after `parallaxOcclusion` (before `main`):

```glsl
// Soft parallax self-shadow: march from the parallax UV toward the light,
// accumulating how far blockers rise above the ray.
float parallaxShadow(vec2 uv, vec3 lightT) {
    if (lightT.z <= 0.0) return 1.0;
    const float n = 16.0;
    const float strength = 12.0;
    float startDepth = 1.0 - texture(u_heightMap, uv).r;
    float layerDepth = startDepth / n;
    vec2 dUV = (lightT.xy / lightT.z) * u_heightScale / n;
    float curDepth = startDepth - layerDepth;
    vec2 curUV = uv + dUV;
    float occ = 0.0;
    while (curDepth > 0.0) {
        float d = 1.0 - texture(u_heightMap, curUV).r;
        if (d < curDepth) occ += (curDepth - d);
        curDepth -= layerDepth;
        curUV += dUV;
    }
    return 1.0 - clamp(occ * strength, 0.0, 1.0);
}
```

- **G-buffer ordering:** new attachment is index 3; SSAO (`colorAttachment(1)`,`(2)`) and emissive (`colorAttachment(2)`) untouched.
- **Height convention:** fixed as white = raised (`depth = 1 - height`) across POM and self-shadow; T2 Step 6 and T3 Step 8 both carry an explicit "if inverted, flip and re-shoot" check since the direction is only verifiable visually.

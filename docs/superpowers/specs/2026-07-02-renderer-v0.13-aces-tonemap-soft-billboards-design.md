# Renderer v0.13 — ACES Tonemap & Soft Light Billboards — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Engine v0.13 — two final-image polish items: ACES filmic tonemapping
with an exposure control (replacing Reinhard in the composite), and depth-occluded
soft-particle light billboards (replacing the always-on-top v0.12 billboards).
**Builds on:** v0.12 emissive point-light billboards (merged to `main`).

## 1. Goal & Motivation

This is the first of three milestones split out from a larger request (v0.13 polish,
v0.14 `.hdr` environments, v0.15 light culling). Two small, independent,
low-risk improvements:

- **ACES tonemap + exposure** — Reinhard (`c/(c+1)`) desaturates and rolls
  highlights off flatly. The Narkowicz ACES filmic curve, with a manual exposure
  multiply, gives punchier contrast and better-preserved highlight colour.
- **Soft / depth-occluded billboards** — v0.12's light orbs are always-on-top; a
  foreground cube does not occlude them and grazing intersections show a hard edge.
  A G-buffer-based soft-particle fade fixes both, reusing data already stored.

## 3. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Tonemap | Narkowicz ACES filmic approximation, replacing Reinhard in `compositeBloom` |
| Exposure | Constant `u_exposure` uniform (default `1.0`), applied before the curve; no auto-exposure |
| Billboard occlusion | Soft-particle fade from the G-buffer world-position (RT2); no depth test, no depth blit |
| Fade | `fade = smoothstep(0, 0.5, sceneDist - fragDist)`; sky (G-buffer `.w == 0`) → `fade = 1` |
| Billboard input | `drawLightBillboards(int count, uint32_t gWorldPos)` gains the world-pos texture |
| Testing | No new unit test (both in-shader; CPU-duplicating the curve breaks DRY); existing 36 stay green |
| DoD | Filmic contrast/highlights; light orbs occluded by foreground cubes with soft edges |

## 4. Part A — ACES tonemap + exposure

`createCompositeProgram`'s fragment shader (currently Reinhard) becomes:

```glsl
uniform float u_exposure;
vec3 aces(vec3 x) {
  const float a = 2.51, b = 0.03, c = 2.43, d = 0.59, e = 0.14;
  return clamp((x * (a * x + b)) / (x * (c * x + d) + e), 0.0, 1.0);
}
void main() {
  vec3 hdr = (texture(u_scene, v_uv).rgb +
              texture(u_bloom, v_uv).rgb * u_bloomIntensity) * u_exposure;
  vec3 c = aces(hdr);
  c = pow(c, vec3(1.0 / 2.2));   // gamma
  fragColor = vec4(c, 1.0);
}
```

`compositeBloom` sets `u_exposure = 1.0` (alongside the existing `u_bloomIntensity`).
Nothing else in the frame changes.

## 5. Part B — Soft / depth-occluded billboards

The emissive vertex shader additionally outputs the billboard fragment's world
position (`v_worldPos = world`). The fragment shader occludes/fades using the
G-buffer world-position:

```glsl
in vec3 v_worldPos;
layout(std140, binding = 0) uniform Camera { ...; vec4 u_cameraPos; ...; };
uniform sampler2D u_gWorldPos;
void main() {
  float falloff = smoothstep(1.0, 0.0, length(v_local));
  vec4 sceneWP = texelFetch(u_gWorldPos, ivec2(gl_FragCoord.xy), 0);
  float fade = 1.0;
  if (sceneWP.w > 0.5) {   // geometry present (sky has w == 0)
    float sceneDist = length(sceneWP.xyz - u_cameraPos.xyz);
    float fragDist = length(v_worldPos - u_cameraPos.xyz);
    fade = smoothstep(0.0, 0.5, sceneDist - fragDist);
  }
  fragColor = vec4(v_color * falloff * fade, 1.0);
}
```

- A billboard fragment behind geometry (`fragDist > sceneDist`) → `fade = 0`
  (occluded). Near a surface → soft fade (no hard edge). Against the sky → `fade =
  1`.
- `texelFetch(..., ivec2(gl_FragCoord.xy), 0)` reads the G-buffer texel directly —
  the billboard pass draws at full scene resolution into `sceneFBO`, matching the
  G-buffer resolution, so no UV normalization is needed.
- `u_cameraPos` comes from the Camera UBO (binding 0), already declared in the
  emissive shader.

`drawLightBillboards(int count, uint32_t gWorldPos)` binds the world-pos texture to
unit 0 and sets `u_gWorldPos = 0` (blend/additive/no-depth-test as v0.12). The
`Renderer` passes `m_gbufferFBO->colorAttachment(2)`.

## 6. Components

- **Backend:** `compositeBloom` shader → ACES + `u_exposure`; emissive shader →
  `v_worldPos` + soft-particle fade; `drawLightBillboards` gains the `gWorldPos`
  parameter and binds it.
- **Renderer:** `drawLightBillboards(m_pointLightCount,
  m_gbufferFBO->colorAttachment(2))`.
- `BotArenaGame`: unchanged.

## 7. Testing

- **Unit:** none new — both changes are in-shader; a CPU copy of the ACES curve or
  the fade math purely to test would duplicate shader logic (DRY). The existing 36
  Catch2 cases stay green.
- **Behavioral:** `BOTARENA_SCREENSHOT` shows filmic contrast and cleaner highlight
  colour (vs the flatter Reinhard), and light orbs correctly occluded by foreground
  cubes with soft edges where they graze the swarm.

## 8. Out of scope (later milestones)

Auto/eye-adaptation exposure (a log-luminance reduction pass), alternative tonemap
operators (AgX, Uncharted2), textured light sprites, and HDR flares/streaks. This
milestone is the minimal filmic-tonemap + soft-billboard polish.

# Engine v0.22 — Assimp Model Loading & Viewer — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Add Assimp, load the vendored `.obj` models into the engine's mesh path
(position+normal), and add a `models_game` viewer with an ImGui model picker. Other
games untouched.
**Builds on:** v0.21 ImGui + the deferred mesh pipeline, on `main`. Renderer + fourth
game example.

## 1. Goal & Motivation

The engine only renders its built-in unit cube. v0.22 imports real `.obj` models via
Assimp into the existing mesh path and adds a viewer to inspect them. Models render
with solid-color materials (the deferred renderer shades per-material colors, not
textures); `.mtl`/texture support is a follow-up.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Library | `assimp` (in the vcpkg registry); `assimp::assimp` |
| Load flags | `aiProcess_Triangulate | aiProcess_GenSmoothNormals | aiProcess_JoinIdenticalVertices | aiProcess_PreTransformVertices` |
| Mesh data | All sub-meshes merged into one interleaved **position+normal** vertex buffer + index buffer (indices offset per sub-mesh) → `VertexArray` → `registerMesh` |
| Materials | Ignored — models render with an engine solid-color material (textures/`.mtl` deferred) |
| Fit | `fitToUnitTransform` centers + uniform-scales each model to a unit box, so different-scale models view consistently |
| Demo | New `models_game` (`games/models/`): loads a curated set, renders the selected model rotating, ImGui picker |
| Tested core | `computeBounds` / `fitToUnitTransform` in `engine/assets/MeshBounds.hpp` (pure, no Assimp/GL) |
| Untouched | `bot_arena`/`arena_game`/`particles_game` |
| DoD | `models_game` screenshot shows a loaded model (Suzanne) + the picker panel |

## 3. Pure core (`engine/assets/MeshBounds.hpp`)

```cpp
struct AABB {
  glm::vec3 min{0.0f};
  glm::vec3 max{0.0f};
};

// Min/max over the points (count == 0 -> zero AABB).
AABB computeBounds(const glm::vec3* points, std::size_t count);

// Center at origin + uniform scale so the largest extent becomes 1.
glm::mat4 fitToUnitTransform(const AABB& b);
```

`fitToUnitTransform`: `center = (min+max)/2`, `extent = max-min`, `s = 1/max(extent.x,
extent.y, extent.z)` (or 1 if degenerate); returns `scale(s) * translate(-center)`.

## 4. Model loader (`engine/assets/ModelLoader.{hpp,cpp}`)

```cpp
struct Model {
  MeshHandle mesh = 0;
  AABB bounds{};
  bool valid = false;
};

Model loadModel(const std::string& path, ResourceRegistry& registry);
```

Assimp `Importer::ReadFile(path, flags)`; on failure (null scene / incomplete / no
root) logs the importer error and returns `{valid=false}`. Otherwise iterates
`scene->mMeshes`, appends `{position.xyz, normal.xyz}` per vertex (fallback normal
`(0,1,0)` if absent) and the triangulated indices (offset by the running vertex base),
builds a `VertexArray` (layout `{Float3 "a_position"}, {Float3 "a_normal"}`) via
`VertexBuffer::Create`/`IndexBuffer::Create`, `registerMesh`es it, and fills `bounds`
via `computeBounds`. Requires a live GL context (creates GL buffers) — called from a
layer's `onRender`.

## 5. Viewer (`games/models/`)

`models_game` = `main.cpp` + `ModelsGame.{hpp,cpp}`, linking `bot_arena_engine`. A
curated list of `{name, "meshes/<file>.obj"}` (Suzanne, Teapot, Sphere, Torus,
Spaceship, Statue). On the first `onRender`, `loadModel(assetPath(path), registry)`
each; keep only the valid ones. Renders the selected model with
`fitToUnitTransform(bounds) * rotate(angle)` and a solid material, on a ground plane,
under an orbit camera + a key light. `onUpdate` advances `angle` when auto-rotate is
on. `onImGuiRender` = a "Model Viewer" panel: a `Combo` of model names + an auto-rotate
checkbox + a triangle/vertex count readout. Default selection = Suzanne.

## 6. Testing

- **Unit (Catch2, no Assimp/GL):** `computeBounds` (min/max over a small point set;
  empty → zero) and `fitToUnitTransform` (a known box maps its center to the origin
  and its max corner to `+0.5` on the largest axis).
- **Behavioral:** `models_game` screenshot shows a loaded, centered model (Suzanne)
  with the "Model Viewer" picker; `bot_arena`/`arena_game`/`particles_game` unchanged.

## 7. Out of scope (later)

Textured/`.mtl` PBR materials (needs an RGBA texture path in the deferred shader),
skeletal/keyframe animation, glTF/FBX imports, instanced model rendering, and mesh LOD.
This milestone is Assimp `.obj` geometry loading + the viewer.

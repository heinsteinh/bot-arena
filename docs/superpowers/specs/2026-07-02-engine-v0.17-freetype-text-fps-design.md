# Engine v0.17 — FreeType Text Rendering & FPS Overlay — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** A first 2D text path — FreeType font-atlas baking, a general `Texture2D`
resource, a pure text-layout helper, a screen-space text-quad renderer, and an
app-level on-screen FPS counter shown by both games.
**Builds on:** v0.16 (merged to `main`). A renderer/tooling milestone (separate from
the gameplay roadmap).

## 1. Goal & Motivation

The engine has no 2D/text rendering — everything is the 3D deferred pipeline. This
milestone adds a Hazel-style font system (FreeType → glyph atlas → screen-space quad
batch) and uses it for an always-on **FPS overlay** so performance is visible while
running either game.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Font library | **FreeType** (in the local vcpkg registry); added to `vcpkg.json` + CMake |
| Font asset | Vendor `assets/fonts/DejaVuSans.ttf` (copied from the system; DejaVu is freely redistributable) |
| Glyph set | Printable ASCII 32–126, baked at 32 px into one **R8** atlas (shelf-packed, 1 px padding) |
| 2D texture | New `Texture2D` (DSA, `GL_R8`), mirroring the `TextureCube` `Create(...)` pattern |
| Layout | Pure `layoutText(glyphs, text, x, y, scale) -> std::vector<TextQuad>` (header-only, no GL/FreeType) — the TDD anchor |
| Text draw | Inline text shader in `OpenGLBackend` (matches existing inline-GLSL pattern) + a dynamic quad VBO; drawn to the default framebuffer after `compositeBloom`, alpha-blended, depth off |
| API | `Renderer::drawText(font, text, x, y, scale, color)` enqueues; `endFrame` flushes after composite (so text is in screenshots) |
| FPS overlay | **App-level**: `Application` owns a debug `Font` + smoothed FPS, queues `"FPS: NN"` each frame — both `bot_arena` and `arena_game` get it; neither game changes |
| DoD | Both games' screenshots show a legible `FPS: NN` top-left |

## 3. Coordinate & layout convention

Text is laid out in **pixel space, y-down, origin top-left**. `(x, y)` is the pen at
the baseline. For glyph `g` at scale `s`:

```
x0 = x + g.bearing.x * s
y0 = y - g.bearing.y * s          // bearing.y = baseline-to-top; y-down
x1 = x0 + g.size.x * s
y1 = y0 + g.size.y * s
uv = (g.uvMin, g.uvMax)
pen.x += g.advance * s
```

Glyphs with zero size (e.g. space) advance the pen but emit no quad; characters
absent from the map are skipped. The backend converts pixel corners to NDC using the
screen size when building the vertex buffer, so the shader itself is trivial.

## 4. Components

### 4.1 `Texture2D` (`engine/renderer/Texture2D.hpp`, `opengl/OpenGLTexture2D.*`)

```cpp
class Texture2D {
 public:
  virtual ~Texture2D() = default;
  virtual void setData(const void* data, uint32_t size) = 0;  // R8 pixels
  virtual void bind(uint32_t unit) const = 0;
  virtual uint32_t rendererID() const = 0;
  virtual uint32_t width() const = 0;
  virtual uint32_t height() const = 0;
  static Ref<Texture2D> Create(uint32_t width, uint32_t height);  // GL_R8
};
```

OpenGL impl: `glCreateTextures(GL_TEXTURE_2D)`, `glTextureStorage2D(…, GL_R8, w, h)`,
linear filter + clamp-to-edge; `setData` uses `glPixelStorei(GL_UNPACK_ALIGNMENT, 1)`
+ `glTextureSubImage2D(…, GL_RED, GL_UNSIGNED_BYTE, data)`.

### 4.2 Glyph types + layout (`engine/renderer/text/TextLayout.hpp`, header-only)

```cpp
struct Glyph {
  glm::vec2 size{0.0f};     // px
  glm::vec2 bearing{0.0f};  // px (left, top)
  float advance = 0.0f;     // px
  glm::vec2 uvMin{0.0f};
  glm::vec2 uvMax{0.0f};
};
using GlyphMap = std::array<Glyph, 128>;  // ASCII-indexed

struct TextQuad {
  float x0, y0, x1, y1;  // pixel-space corners
  float u0, v0, u1, v1;  // atlas UVs
};

std::vector<TextQuad> layoutText(const GlyphMap& glyphs, std::string_view text,
                                 float x, float y, float scale);
```

Pure, EnTT/GL/FreeType-free — the unit-test anchor.

### 4.3 `Font` (`engine/renderer/text/Font.*`)

`static Ref<Font> Load(const std::string& ttfPath, uint32_t pixelSize)` — FreeType
bakes ASCII 32–126 into an R8 atlas (shelf pack, 1 px pad), uploads it to a
`Texture2D`, and fills a `GlyphMap`. Accessors: `const GlyphMap& glyphs() const`,
`uint32_t atlasRendererID() const`, `void bindAtlas(uint32_t unit) const`. Requires a
current GL context (uploads the texture). Uses `FT_Set_Pixel_Sizes`,
`FT_Load_Char(…, FT_LOAD_RENDER)`; `advance = glyph->advance.x >> 6`,
`bearing = (bitmap_left, bitmap_top)`, `size = (bitmap.width, bitmap.rows)`.

### 4.4 Backend text primitive (`RenderBackend` + `OpenGLBackend`)

```cpp
virtual void drawText(uint32_t atlasTextureId, const std::vector<TextQuad>& quads,
                      int screenW, int screenH, const glm::vec4& color) = 0;
```

OpenGL impl builds an inline text program (vs: NDC pos + uv passthrough; fs:
`out = vec4(color.rgb, color.a * texture(atlas, uv).r)`) and a dynamic VBO in init.
`drawText`: expand quads to 6 verts each (pixel→NDC via screenW/H), orphan-upload,
`glEnable(GL_BLEND)` + `GL_SRC_ALPHA/GL_ONE_MINUS_SRC_ALPHA`, depth test off, bind the
atlas, `glDrawArrays(GL_TRIANGLES, 0, 6*quads)`, then restore depth/blend state.

### 4.5 `Renderer` API + flush

`void drawText(const Font&, std::string_view, float x, float y, float scale, const
glm::vec4& color)` — runs `layoutText(font.glyphs(), …)` and appends a
`{atlasId, quads, color}` batch to a per-frame list (cleared in `beginFrame`).
`endFrame`, right after `compositeBloom` (default framebuffer still bound), replays
each batch via `m_backend->drawText(…, m_width, m_height, …)`.

### 4.6 FPS overlay (`Application`)

`Application` loads `m_debugFont = Font::Load(BOTARENA_ASSET_DIR "/fonts/DejaVuSans.ttf",
32)` in its constructor (GL context already current). Each frame it updates a smoothed
FPS (`fps = dt > 1e-5 ? 1/dt : 0`; EMA, factor 0.1) and, **after the layers' `onRender`
and before `endFrame`**, calls `m_renderer->drawText(*m_debugFont, "FPS: <n>", 8, 24,
1.0f, {1,1,1,1})`. No game code changes.

## 5. Testing

- **Unit (Catch2, no GL/FreeType):** `layoutText` with a hand-built `GlyphMap` —
  single glyph places the quad by bearing/size and copies UVs; a two-glyph string
  advances the pen by `advance`; a space advances but emits no quad; an empty string
  yields no quads; an unmapped character is skipped.
- **Behavioral:** `bot_arena` and `arena_game` screenshots each show a legible
  `FPS: NN` top-left over the scene. (The value is arbitrary in a one-frame headless
  capture; it proves the font atlas → layout → blended draw path end-to-end.)

## 6. Out of scope (later)

Multiple simultaneous fonts/sizes, SDF/scalable glyphs, kerning, rich text/markup,
UTF-8 beyond ASCII, a general 2D sprite/quad renderer, text alignment/wrapping, and an
ImGui debug panel. This milestone is: font atlas → text layout → on-screen FPS.

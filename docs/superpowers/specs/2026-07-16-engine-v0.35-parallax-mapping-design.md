# Engine v0.35 — Parallax Occlusion Mapping + Self-Shadowing — Design Spec

**Date:** 2026-07-16
**Status:** Approved for planning
**Scope:** Add Parallax Occlusion Mapping (POM) to the deferred g-buffer geometry pass on the tangent-space seam v0.34 built, plus correct per-light parallax self-shadowing carried through a new g-buffer target and consumed by the directional light in the deferred lighting pass. A `normalmap_demo` third wall shows `flat | normal | normal+parallax` under a grazing directional light.
**Builds on:** the deferred renderer on `main` (v0.28–v0.34 merged; deferred/PCF/PBR/SSAO/IBL/bloom + tangent-space normal mapping already present).

## 1. Goal & Motivation

Normal mapping (v0.34) perturbs the per-fragment normal but the surface stays geometrically flat — at grazing angles bricks do not occlude their mortar, and there is no motion parallax between raised and recessed detail. POM ray-marches a height field in tangent space and shifts the texture coordinate before sampling, giving true parallax depth and self-occlusion from a single quad. Because the shifted UV feeds both the albedo and the normal sample, POM and normal mapping reinforce each other. Adding a per-light self-shadow term lets the raised detail cast soft shadows into the crevices, completing the depth illusion.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Algorithm | **Parallax Occlusion Mapping** — steep ray-march (layer count scaled by view angle) + one interpolation between the last two layers for a smooth intersection |
| Height source | Dedicated `u_heightMap` (grayscale, sampled `.r`); **white = raised**, in-shader `depth = 1 - height`. `Material.heightMap` optional (null → no parallax) |
| Height scale | `Material.heightScale` (default `0.05`), UV-space displacement depth |
| TBN / view / light vectors | Reuse the v0.34 geometric-normal TBN; view vector from `u_cameraPos` (Camera UBO, binding 0); light vector from `u_lightDir` (**existing** Light UBO, binding 1 — already uploaded before the geometry pass) |
| Self-shadowing | **Correct per-light**: geometry pass writes a soft occlusion term to a **4th g-buffer target** `gShadow`; the lighting pass multiplies **only the directional light** contribution by it |
| Shadow-casting light | The engine's **directional light** — the same "sun" that drives the PCF shadow map — now also drives parallax self-shadow |
| Demo | `normalmap_demo` gains a **third wall** (`flat | normal | normal+parallax`); directional light grazes the walls; `BOTARENA_LIGHT=0|1` rotates it |
| Demo asset | Generate `assets/textures/brick_h.png` from `brick_d` luminance (blur + contrast), commit it |
| Reserved | Parallax silhouette edge-clipping/discard; per-light self-shadow for point lights; packing height into the normal map's alpha; per-material min/max layer tuning |

## 3. Components & changes

### 3.1 `Material` (`ResourceRegistry.hpp`)
Append two fields at the **end** (so existing positional initializers such as `{{...}, 0.0f, 0.9f, s}` keep working, exactly as `normalMap` was appended in v0.34):
```cpp
struct Material {
  glm::vec4 baseColor{1.0f};
  float metallic = 0.0f;
  float roughness = 0.5f;
  ShaderHandle shader = 0;
  Ref<Texture2D> albedo = nullptr;
  Ref<Texture2D> normalMap = nullptr;
  Ref<Texture2D> heightMap = nullptr;   // new; null -> no parallax
  float heightScale = 0.05f;            // new; UV-space displacement depth
};
```

### 3.2 4th g-buffer target `gShadow`
`Renderer` constructor: append one color format to the g-buffer spec:
```cpp
gbufferSpec.colorFormats = {FramebufferFormat::RGBA8,    // gAlbedo
                            FramebufferFormat::RGBA16F,   // gNormal
                            FramebufferFormat::RGBA16F,   // gWorldPos
                            FramebufferFormat::RGBA8};    // gShadow (parallax self-shadow)
```
The OpenGL framebuffer impl is already generic over N color attachments (it builds `glNamedFramebufferDrawBuffers` from `colorFormats`), so no framebuffer-impl change is required. SSAO reads attachments 1 & 2 and the emissive pass reads attachment 2 — unchanged; the new attachment is index 3.

### 3.3 `mesh.glsl` geometry pass
**Vertex stage:** unchanged from v0.34 (already outputs `v_worldNormal`, `v_worldTangent`, `v_worldPos`, `v_uv`).

**Fragment stage** gains the Camera UBO (binding 0, for `u_cameraPos`), the Light UBO (binding 1, for `u_lightDir`), the height uniforms, and the 4th output:
```glsl
layout(std140, binding = 0) uniform Camera { mat4 u_view; mat4 u_projection;
    mat4 u_viewProjection; vec4 u_cameraPos; };
layout(std140, binding = 1) uniform Light  { mat4 u_lightViewProj; vec4 u_lightDir; };

uniform sampler2D u_heightMap;
uniform int   u_hasHeight;
uniform float u_heightScale;

layout(location = 3) out vec4 gShadow;   // .r = directional self-shadow (1 = lit)
```
Fragment order:
1. Build the TBN from the **geometric** vertex normal + tangent (Gram-Schmidt), as in v0.34.
2. `vec2 uv = v_uv; float selfShadow = 1.0;`
3. If `u_hasHeight == 1`:
   - `vec3 viewT  = normalize(transpose(TBN) * (u_cameraPos.xyz - v_worldPos));`
   - `uv = parallaxOcclusion(v_uv, viewT);` (§3.4)
   - `vec3 lightT = normalize(transpose(TBN) * normalize(u_lightDir.xyz));`
   - `selfShadow = parallaxShadow(uv, lightT);` (§3.5)
4. Sample albedo **and** normal at `uv` (normal mapping uses the shifted UV).
5. Write `gAlbedo / gNormal / gWorldPos` as before, **and always** `gShadow = vec4(selfShadow, 0.0, 0.0, 1.0)` — every geometry fragment writes it, so the 4th draw buffer is always defined and non-parallax materials write `1.0` (fully lit).

### 3.4 POM function
```glsl
vec2 parallaxOcclusion(vec2 uv, vec3 viewT) {
    const float minLayers = 8.0, maxLayers = 32.0;
    float n = mix(maxLayers, minLayers, clamp(abs(viewT.z), 0.0, 1.0));
    float layerDepth = 1.0 / n;
    vec2  P = viewT.xy / viewT.z * u_heightScale;   // total UV shift at depth 1
    vec2  dUV = P / n;
    float curDepth = 0.0;
    vec2  curUV = uv;
    float d = 1.0 - texture(u_heightMap, curUV).r;  // depth = 1 - height
    while (curDepth < d) {
        curUV -= dUV;
        d = 1.0 - texture(u_heightMap, curUV).r;
        curDepth += layerDepth;
    }
    vec2  prevUV = curUV + dUV;                      // last step before the hit
    float after  = d - curDepth;
    float before = (1.0 - texture(u_heightMap, prevUV).r) - (curDepth - layerDepth);
    float w = after / (after - before);
    return mix(curUV, prevUV, w);                    // smooth intersection
}
```

### 3.5 Parallax self-shadow function
Marches from the parallax UV toward the light, accumulating soft occlusion. Concept (final constants tuned in the screenshot step):
```glsl
float parallaxShadow(vec2 uv, vec3 lightT) {
    if (lightT.z <= 0.0) return 1.0;                 // light grazes/behind: no term
    const float n = 16.0;
    float startDepth = 1.0 - texture(u_heightMap, uv).r;
    float layerDepth = startDepth / n;
    vec2  dUV = (lightT.xy / lightT.z) * u_heightScale / n;
    float curDepth = startDepth - layerDepth;
    vec2  curUV = uv + dUV;
    float occ = 0.0;
    while (curDepth > 0.0) {
        float d = 1.0 - texture(u_heightMap, curUV).r;
        if (d < curDepth) occ += (curDepth - d);     // blocker above ray -> penumbra
        curDepth -= layerDepth;
        curUV += dUV;
    }
    return 1.0 - clamp(occ * u_shadowStrength, 0.0, 1.0);
}
```
`u_shadowStrength` is a shader constant (not a material field this slice); the soft term yields partial shadow for partial occlusion. Screenshot-tuned.

### 3.6 Backend `executeGeometry` — bind the height map
Mirror the albedo (unit 0) and normal (unit 1) blocks for the height map on **unit 2**:
```cpp
if (mat.heightMap) {
  mat.heightMap->bind(2);
  shader->setInt("u_heightMap", 2);
  shader->setInt("u_hasHeight", 1);
  shader->setFloat("u_heightScale", mat.heightScale);
} else {
  shader->setInt("u_hasHeight", 0);
}
```

### 3.7 Lighting pass — consume `gShadow`
- `Renderer::endFrame` passes the new attachment: `lightingPass(..., m_gbufferFBO->colorAttachment(2), m_shadowFBO->depthAttachment(), m_gbufferFBO->colorAttachment(3))`.
- `RenderBackend::lightingPass` / `OpenGLBackend::lightingPass` take an extra `uint32_t gShadow`, bound to **texture unit 9** (units 0–8 are in use) with `u_gShadow`.
- The inline lighting fragment shader multiplies **only the directional term**:
  ```glsl
  float pShadow = texture(u_gShadow, v_uv).r;
  vec3 L = normalize(u_lightDir.xyz);
  float shadow = shadowPCF(worldPos, max(dot(N, L), 0.0));
  color += brdf(N, V, L, albedo, metallic, rough, F0, vec3(3.0))
           * (1.0 - shadow) * pShadow;
  ```
  Point lights and IBL/ambient are unchanged.

## 4. Data flow

```
mesh (pos/normal/uv/tangent) + Material{albedo, normalMap, heightMap, heightScale}
  -> executeGeometry: bind albedo(0)/normal(1)/height(2), set u_hasHeight/u_heightScale
  -> mesh.glsl geometry pass:
       TBN, view/light in tangent space (u_cameraPos / u_lightDir UBOs)
       POM shifts uv -> sample albedo + normal at shifted uv
       parallaxShadow -> gShadow.r      (1.0 when no height map)
  -> gAlbedo / gNormal / gWorldPos / gShadow
  -> [unchanged] SSAO (attachments 1,2)
  -> lighting pass: directional term *= (1 - pcfShadow) * gShadow.r; points + IBL untouched
  -> bloom -> composite (ACES + gamma)
```

## 5. Demo — `normalmap_demo` third wall

- Walls (scaled cubes) left→right: **flat** (`albedo`), **normal** (`albedo + normalMap`), **parallax** (`albedo + normalMap + heightMap`, `heightScale ≈ 0.05`).
- The **directional light** (`setLightDirection`) grazes the walls at a low angle — it drives the PCF shadow map **and** the parallax self-shadow. `BOTARENA_LIGHT=0|1` selects two directional angles for before/after screenshots. A soft point light may remain as fill.
- Camera is slightly **oblique** (parallax depth reads best off dead-on).
- Three camera-facing billboard labels ("flat" / "normal" / "parallax", v0.33 world text).
- `assets/textures/brick_h.png` generated from `brick_d` luminance (blur + contrast), committed as a demo asset.

Visual proof: the parallax wall shows recessed mortar with raised bricks whose silhouettes shift under camera motion, and soft self-shadows cast into the crevices that swing with the directional light angle; the normal-only wall shows flat-lit relief without occlusion or self-shadow; the flat wall is plain brick.

## 6. Testing

- **GL/shader path — screenshot-validated** (consistent with the rest of the renderer, which has no unit tests for deferred/PCF/SSAO): `normalmap_demo` at both light presets confirms the parallax wall shows depth + self-shadowing the normal-only wall lacks, and that both respond to the light angle. POM UV-shift direction and the self-shadow strength are tuned in this step.
- **Regression:** existing games (arena/shooter/camera/billboard/text) have `heightMap == null` → `u_hasHeight == 0`, POM skipped, and every fragment writes `gShadow = 1.0`, so the directional light is multiplied by 1.0 — no visual change. SSAO/emissive read attachments 1 & 2, unaffected by the new attachment 3. Shooter/arena screenshots stay identical; full build + suite green.
- **`Material.heightMap` default** is null and `heightScale` default is inert without a map — existing materials render unchanged.

## 7. Risks & mitigations

- **4th draw buffer undefined if not written.** Mitigation: `mesh.glsl` writes `gShadow` on **every** path (1.0 default), so the attachment is always defined.
- **POM UV-shift / height convention inverted** (relief pushes out instead of in). Mitigation: height convention fixed (white = raised, `depth = 1 - height`); direction verified in the screenshot step and flipped if wrong.
- **Self-shadow only correct for the directional light.** Accepted and documented: point-light parallax shadows are reserved; the demo makes the directional light the dominant grazing caster so the term is the visible one.
- **`while`-loop ray-march cost.** Mitigation: layer count scaled by view angle (8–32); self-shadow fixed at 16; gated entirely behind `u_hasHeight`, so only parallax materials pay.
- **Blast radius touches the shared deferred path** (g-buffer spec, lighting pass signature). Mitigation: additive only (new attachment, new sampler, new multiply-by-1.0-default); regression screenshots on shooter + arena confirm no change.

## 8. Open items (deferred, not blocking)

- Parallax silhouette edge-clipping (`discard` when the shifted UV leaves `[0,1]`).
- Per-light parallax self-shadow for point lights.
- Packing height into the normal map's alpha channel (one fewer texture bind).
- Per-material min/max POM layer counts and self-shadow strength.

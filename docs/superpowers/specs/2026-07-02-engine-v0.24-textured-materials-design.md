# Engine v0.24 — Textured Materials — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Load `map_Kd` albedo textures for models — an RGBA `Texture2D`, an
`stb_image` loader, a UV vertex attribute, `mesh.glsl` albedo sampling, and the geometry
pass binding — so textured models (Planet) show their maps. Second half of the material
split.
**Builds on:** v0.23 per-submesh colors, on `main`.

## 1. Goal & Motivation

v0.23 gave each sub-mesh its `.mtl` diffuse color. v0.24 adds the `map_Kd` **albedo
texture**: models with a diffuse texture (e.g. `planet.obj` → `planet_Quom1200.png`)
render textured; models with only a color keep their v0.23 behavior. This needs the
first real texture-sampling path in the mesh pipeline: a UV attribute, an RGBA texture,
and shader sampling.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Texture format | `enum class TextureFormat { R8, RGBA8 }`; `Texture2D::Create(w, h, format = R8)`. Fonts keep R8 (unchanged). |
| Loading | `engine/assets/TextureLoader` (`STB_IMAGE_IMPLEMENTATION`): `loadTexture(path) -> Ref<Texture2D>`, forced RGBA, **V-flipped**; null on failure |
| Vertex layout | position+normal+**uv** (Float2); the built-in cube gets UVs; models include texcoords (0,0 if absent) |
| Shader | `mesh.glsl` gains `a_uv` + `u_albedoMap`/`u_hasAlbedo`; `albedo = u_hasAlbedo==1 ? texture(u_albedoMap, v_uv).rgb * u_baseColor.rgb : u_baseColor.rgb` |
| Material | `Material` gains `Ref<Texture2D> albedo`; the geometry pass binds it (unit 0) + sets the uniforms per material |
| Path resolve | `resolveTexturePath(modelPath, texRef)` — join the `.obj` directory + the texture name; absolute paths pass through (pure, tested) |
| Demo | Vendor `assets/Objects/Planet/` (obj + mtl + `planet_Quom1200.png`); add "Planet" to the viewer |
| Untouched | Solid-material games (`bot_arena`/`arena_game`/`particles_game`) render unchanged |
| DoD | `models_game` shows the textured planet (its map on the sphere) |

## 3. RGBA `Texture2D`

`Texture2D::Create(uint32_t w, uint32_t h, TextureFormat format = TextureFormat::R8)`.
`OpenGLTexture2D(w, h, format)` uses `GL_R8`/`GL_RED` or `GL_RGBA8`/`GL_RGBA` for
`glTextureStorage2D` and `setData`'s `glTextureSubImage2D`. `setData` keeps
`glPixelStorei(GL_UNPACK_ALIGNMENT, 1)`.

## 4. Texture loader (`engine/assets/TextureLoader.{hpp,cpp}`)

```cpp
Ref<Texture2D> loadTexture(const std::string& path);
```

`.cpp` defines `STB_IMAGE_IMPLEMENTATION`, `stbi_set_flip_vertically_on_load(true)`,
`stbi_load(path, &w, &h, &c, 4)` (force RGBA); on failure logs + returns `nullptr`;
otherwise `Texture2D::Create(w, h, RGBA8)`, `setData(pixels, w*h*4)`, `stbi_image_free`.

## 5. Path resolution (`engine/assets/TexturePath.hpp`, pure)

```cpp
std::string resolveTexturePath(const std::string& modelPath,
                               const std::string& textureRef);
```

If `textureRef` is absolute (starts with `/`), return it. Otherwise return
`dir(modelPath) + "/" + textureRef` (the `.mtl` references textures relative to the
model). Backslashes in `textureRef` are normalized to `/`, and any leading directory in
`textureRef` is kept (join, don't strip).

## 6. UV attribute + shader

- Mesh layout: `{Float3 a_position}, {Float3 a_normal}, {Float2 a_uv}`.
- `Renderer::initBuiltins` cube: 24 verts extended to `pos(3)+normal(3)+uv(2)`; each
  face's 4 verts get UVs `(0,0),(1,0),(1,1),(0,1)`.
- `mesh.glsl` vertex: add `layout(location = 2) in vec2 a_uv; out vec2 v_uv; v_uv = a_uv;`.
- `mesh.glsl` fragment: add `in vec2 v_uv; uniform sampler2D u_albedoMap; uniform int
  u_hasAlbedo;` and compute `albedo` as above → `gAlbedo = vec4(albedo, u_metallic)`.
- The shadow pass shader (position-only) is unaffected.

## 7. Material + geometry pass

- `Material` (in `ResourceRegistry.hpp`) gains `Ref<Texture2D> albedo = nullptr;`
  (`#include "engine/renderer/Texture2D.hpp"`).
- `OpenGLBackend::executeGeometry`, in the per-material block: after the color/metallic/
  roughness uniforms, `if (mat.albedo) { mat.albedo->bind(0);
  shader->setInt("u_albedoMap", 0); shader->setInt("u_hasAlbedo", 1); } else {
  shader->setInt("u_hasAlbedo", 0); }`.

## 8. Loader `map_Kd`

In `ModelLoader`, per Assimp material: `mat->GetTexture(aiTextureType_DIFFUSE, 0,
&texPath)`; on success `loadTexture(resolveTexturePath(modelPath, texPath.C_Str()))`
and set `material.albedo` (kept alongside the v0.23 `Kd` color). Vertex data includes
`mesh->mTextureCoords[0]` (or `(0,0)`).

## 9. Testing

- **Unit (Catch2, pure):** `resolveTexturePath` — relative name joined to the model
  directory; a nested relative path kept; an absolute path passed through; backslashes
  normalized.
- **Behavioral:** `models_game` logs `Loaded model .../planet.obj (...)` and the
  texture load; the screenshot shows the planet textured (its surface map, not flat
  color). `bot_arena` renders unchanged (regression check — its cube now has UVs but no
  albedo map).

## 10. Out of scope

Normal / metallic / roughness / emissive maps, mipmaps, `Ns`→roughness, embedded
textures, and texture caching/dedup across materials.

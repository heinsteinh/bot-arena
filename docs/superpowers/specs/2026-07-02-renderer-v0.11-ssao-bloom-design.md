# Renderer v0.11 — Screen-Space Post: SSAO + Bloom — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Engine v0.11 — two screen-space post-processing effects on the deferred
pipeline: SSAO (ambient occlusion feeding the IBL ambient) before lighting, and
bloom (HDR glow) after lighting, folded into the composite.
**Builds on:** v0.10 image-based lighting (merged to `main`).

## 1. Goal & Motivation

The deferred G-buffer + HDR pipeline is now complete through IBL. Two classic
screen-space effects add depth and punch, at opposite ends of the lighting pass:

- **SSAO** — approximate ambient occlusion from the G-buffer, darkening crevices
  and contacts. It multiplies the IBL ambient (the `AO = 1` slot v0.10 left open).
- **Bloom** — bright HDR pixels (sun, speculars, point lights) bleed into a soft
  glow, added before the existing tonemap.

They share the deferred G-buffer, the HDR scene framebuffer, the fullscreen-quad
machinery, and the `Framebuffer` RHI; they touch different pipeline stages and no
shared code path, so one milestone is coherent.

## 2. Roadmap context (this spec is v0.11 only)

| Milestone | Adds |
| --- | --- |
| v0.1–v0.10 (done) | …, deferred G-buffer, PBR, environment/skybox, IBL. |
| **v0.11 (this spec)** | SSAO (hemisphere kernel, procedural rotation) into the IBL ambient; threshold bloom (bright-pass + Gaussian) into the composite. |
| Later | Temporal AO / HBAO-GTAO, karis-average / lens-dirt bloom, exposure / auto-exposure, a general `Texture2D` resource, light culling. |

## 3. Decisions (locked)

| Decision | Choice |
| --- | --- |
| SSAO technique | Classic view-space hemisphere SSAO; ~32-sample kernel generated CPU-side; per-pixel rotation via a procedural hash (no noise texture, no `Texture2D`) |
| SSAO buffers | Full-res `RGBA8`: raw AO + 4×4-box-blurred AO (use `.r`) |
| SSAO into lighting | Multiplies **only** the IBL ambient (`ambient *= ao`); direct light unaffected; AO on texture unit 8 |
| Bloom bright-pass | Luminance threshold `1.0`; output to a **half-res** `RGBA16F` buffer |
| Bloom blur | Separable 5-tap Gaussian, ping-pong two half-res buffers, 5 H/V pairs |
| Composite | `scene + bloom * intensity` then Reinhard + gamma (replaces the plain composite blit) |
| Kernel | `generateSSAOKernel(count)` — deterministic, unit-tested |
| Unchanged | Direct Cook-Torrance, IBL, shadows, skybox |
| DoD | Visible AO in crevices/contacts + bloom glow on the sun/speculars/point lights |

## 4. Architecture & data flow

```
Renderer::endFrame
  shadow  → shadow map
  geometry → G-buffer (albedo/metallic, normal/roughness, worldpos, depth)
  // --- SSAO (new, before lighting) ---
  beginPass(ssaoFBO);      ssaoPass(gNormal, gWorldPos)        → AO raw
  beginPass(ssaoBlurFBO);  ssaoBlur(ssaoFBO.color)             → AO blurred
  setAO(ssaoBlurFBO.color)
  // --- lighting (ambient ×= AO on unit 8) ---
  beginPass(sceneFBO);     lightingPass(gAlbedo,gNormal,gWorldPos,shadowMap) → HDR
  // --- bloom (new, after lighting) ---
  beginPass(bloomA half);  bloomExtract(sceneFBO.color)        → bright (half-res)
  ping-pong bloomA/bloomB: bloomBlur(src, horizontal) × (5 H/V pairs) → bloom final
  // --- composite ---
  beginPass(default);      compositeBloom(sceneFBO.color, bloomFinal.color)
```

## 5. SSAO

- **`generateSSAOKernel(int count)`** (`engine/renderer/SSAOKernel.hpp`,
  GL-free): returns `count` `glm::vec3` samples in the `+Z` hemisphere, each within
  the unit sphere and scaled toward the origin (`lerp(0.1,1,i²/count²)`).
  Deterministic (a fixed hash, no `rand`) so it is testable and stable.
- **Backend** owns an SSAO program with a `u_kernel[64]` uniform array (set once
  from `generateSSAOKernel`), `u_radius` (0.5), `u_bias` (0.025), and an
  `u_kernelSize` (32). `ssaoPass(uint32_t gNormal, uint32_t gWorldPos)` binds those
  two G-buffer textures (units 0/1) and draws fullscreen into the bound FBO. The
  shader: `viewPos = (u_view * vec4(worldPos,1)).xyz`, `viewN = mat3(u_view)*normal`;
  build a TBN from a hashed rotation vector; for each kernel sample, project by
  `u_projection`, read the stored world-pos at that UV, transform to view space, and
  accumulate occlusion with a `smoothstep` range check; output `1 - occlusion/size`.
- **`ssaoBlur(uint32_t aoRaw)`** — a 4×4 box blur (fullscreen) → blurred AO.
- **`setAO(uint32_t aoTexture)`** — the lighting pass binds it to unit 8
  (`sampler2D u_ao`) and multiplies the IBL ambient: `color = (kdAmb*diffuseIBL +
  specularIBL) * texture(u_ao, v_uv).r`.

Camera `u_view`/`u_projection` come from the existing Camera UBO (binding 0).

## 6. Bloom

- **`bloomExtract(uint32_t sceneTex)`** — fullscreen bright-pass:
  `lum = dot(c, vec3(0.2126,0.7152,0.0722)); out = lum > u_threshold ? c : 0`,
  threshold `1.0`, into a half-res `RGBA16F` buffer.
- **`bloomBlur(uint32_t src, bool horizontal)`** — separable 5-tap Gaussian
  (weights `0.227, 0.194, 0.121, 0.054, 0.016`); the Renderer ping-pongs two
  half-res buffers for 5 horizontal+vertical pairs.
- **`compositeBloom(uint32_t sceneTex, uint32_t bloomTex)`** — fullscreen:
  `hdr = texture(scene).rgb + texture(bloom).rgb * u_bloomIntensity` (intensity
  `0.6`), then Reinhard `hdr/(hdr+1)` + gamma `1/2.2`. This replaces the current
  `blit`-based composite; the old `blit` is removed (its only caller was the
  composite).

## 7. Renderer

`Renderer` gains: `Ref<Framebuffer> m_ssaoFBO`, `m_ssaoBlurFBO` (full-res, single
`RGBA8`); `Ref<Framebuffer> m_bloomFBO[2]` (half-res, single `RGBA16F`);
constants `kBloomBlurPasses = 5`. `beginFrame` resizes the SSAO buffers to the
window and the bloom buffers to half the window. `endFrame` runs the SSAO
sub-sequence (before lighting), passes AO via `setAO`, then after lighting runs the
bloom extract + ping-pong blur and the `compositeBloom`. `BotArenaGame` does not
change.

## 8. Testing

- **Unit (Catch2, no GL):** `generateSSAOKernel(n)` returns `n` samples, each with
  `z ≥ 0`, `length ≤ 1`, and non-degenerate (not all identical); deterministic
  across calls.
- **Behavioral:** `BOTARENA_SCREENSHOT` shows AO darkening in the swarm's crevices
  and cube/ground contacts, and a soft bloom glow on the sun, speculars, and point
  lights — both clearly distinct from v0.10.

## 9. Out of scope (later milestones)

Temporal AO / denoising, HBAO/GTAO, physically-thresholded (karis-average) bloom or
lens-dirt, exposure / auto-exposure, a general `Texture2D` upload resource, and
light culling. This milestone is classic hemisphere SSAO + threshold Gaussian
bloom; those extend it.

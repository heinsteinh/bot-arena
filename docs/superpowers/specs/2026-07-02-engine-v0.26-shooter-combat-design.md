# Engine v0.26 — Shooter Player Health & Enemy Fire — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Two-way combat in `shooter_game` — the player has health and lives; enemies
face the player and fire back; bullets have factions (green player / red enemy) and
point along their travel. Death respawns; running out of lives resets the run.
**Builds on:** v0.25 shooter core, v0.19 `adjustHealth`, on `main`.

## 1. Goal & Motivation

v0.25 was one-way (the player shoots, enemies only converge). v0.26 makes it a real
firefight: enemies aim at the player and shoot; the player has HP and lives and can die;
bullet streams are colour-coded and oriented along their flight. Reuses the tested
`adjustHealth` and ship-heading helpers — this is combat wiring.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Player | `Health{current, max}` (100); `m_lives = 3` |
| Factions | `Bullet{life, fromPlayer}`: player bullets (**green**) hit enemies; enemy bullets (**red**) hit the player |
| Enemy facing | Enemies face the player: `yaw = headingToYaw(playerPos - enemyPos)` |
| Enemy fire | `Enemy{tier, fireTimer}`; in range (`< kFireRange`) fire toward the player at `kEnemyBulletSpeed` (slower than the player's), staggered cooldown |
| Bullet facing | `yaw = headingToYaw(velocity)` at spawn (+ a Projectile-model offset when rendered) |
| Damage | Enemy bullet `−10`; enemy ram (overlap) `−25` + the enemy is destroyed |
| Death | HP ≤ 0 → `lives--`, respawn at centre with full HP, clear enemy bullets; `lives == 0` → full reset (clear enemies/bullets, `score = 0`, `lives = 3`, HP full) |
| HUD | `Score` / `HP` / `Lives` / `Enemies` |
| DoD | The screenshot shows the player HP dropped, red enemy bullets incoming + green player bullets outgoing, enemies nosed at the player |

## 3. Components (`games/shooter/Components.hpp`)

```cpp
struct Health { float current = 0.0f; float max = 0.0f; };
struct Bullet { float life = 0.0f; bool fromPlayer = true; };
struct Enemy  { int tier = 0; float fireTimer = 0.0f; };
```

`Transform`/`Velocity`/`Player` unchanged. The player entity gains `Health{100, 100}`.

## 4. Simulation (`ShooterGame::stepSim`)

- **Player bullets** spawn with `fromPlayer = true` and `yaw = headingToYaw(velocity)`.
- **Enemies** face the player (`yaw` toward the player), still `seek` for movement; each
  counts down `fireTimer` and, when within `kFireRange`, spawns an enemy bullet
  (`fromPlayer = false`) toward the player (`velocity = normalize(playerPos - enemyPos)
  * kEnemyBulletSpeed`, `yaw` along it) and resets the timer.
- **Hits:** a `fromPlayer` bullet overlapping an enemy destroys both (`score +=`
  weight). A `!fromPlayer` bullet overlapping the player applies `adjustHealth(-10)` and
  is destroyed. An enemy overlapping the player applies `adjustHealth(-25)` and the
  enemy is destroyed.
- **Death/lives:** after damage, if player `current <= 0`: `m_lives--`; if `> 0`
  respawn (reset HP, recentre, destroy all enemy bullets); else reset the run (destroy
  all enemies + bullets, `m_score = 0`, `m_lives = 3`, HP full, recentre).

`adjustHealth(current, delta, max)` is the v0.19 helper (`engine/gameplay/Combat.hpp`).

## 5. Rendering (`ShooterGame::onRender`)

- Register two override materials: `m_playerBulletMat` (bright green) and
  `m_enemyBulletMat` (bright red).
- Bullets render with the Projectile model, **overriding** the sub-mesh material with
  the faction material, rotated `yaw + kBulletYawOffset` so the nose points along
  travel.
- Enemies render at `yaw + kShipYaw` (they already face the player from the sim).
- HUD (v0.17 text): `Score`, `HP: <cur>/<max>`, `Lives: <n>`, `Enemies: <n>`.

The deterministic warm-up now has enemies fire, so the capture shows reduced player HP
and both bullet colours.

## 6. Testing

Combat wiring — verified by screenshot; the reused `adjustHealth` (v0.19) and
`headingToYaw`/`forwardFromYaw`/`circlesOverlapXZ` (v0.25) are already unit-tested and
unchanged.

- **Behavioral:** `shooter_game` shows the player firing green bullets while enemies
  (nosed at the player) fire red bullets back; `HP` is below max and `Lives`/`Score`
  render. Other games unchanged.

## 7. Out of scope

Explosions on kills (next milestone — reuse the particle system), waves, power-ups,
shields, and per-tier enemy fire patterns.

# Engine v0.21 — ImGui Integration & Particle Editor — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Hazel-style ImGui integration on the layer stack (an `ImGuiLayer`, a
`Layer::onImGuiRender` hook, event forwarding + input gating), plus a live particle
editor in `particles_game` (choose a preset, tweak its properties with sliders) and 3
new presets. `bot_arena`/`arena_game` untouched.
**Builds on:** v0.20 particles (merged to `main`). Renderer/tooling milestone.

## 1. Goal & Motivation

ImGui is a dependency (with SDL3 + OpenGL3 bindings) but is not wired up. v0.21
integrates it the Hazel way — as an `ImGuiLayer` driven through the layer stack, with a
`Layer::onImGuiRender` hook every game can override — and demonstrates it with a
particle editor: pick an effect type and tweak its `EmitParams` live with sliders and a
color picker. Every existing/future game gets an ImGui overlay for free.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Style | Hazel-style: `engine::ImGuiLayer` (a `Layer`) + `Layer::onImGuiRender()` hook; app drives `begin()` / per-layer `onImGuiRender` / `end()` |
| Render point | After `renderer.endFrame()` (scene on the default framebuffer), before screenshot/swap — so panels appear in screenshots |
| Events | `Window::setEventCallback`; `SdlWindow` forwards each `SDL_Event`; the app forwards to `ImGui_ImplSDL3_ProcessEvent` and **gates engine Input when ImGui wants the mouse/keyboard** |
| Context | `GraphicsContext::nativeContext()` exposes the `SDL_GLContext` for init |
| Demo | `ParticlesGame::onImGuiRender` = a "Particle Editor" panel; a central live emitter uses the edited `EmitParams` |
| New presets | Jet (tight fast upward), Nova (big radial explosion), Drizzle (arcs up, rains down) — via existing `EmitParams` |
| Untouched | `bot_arena`/`BotArenaGame`, `arena_game`/`ArenaGame` (they don't override `onImGuiRender`) |
| DoD | `particles_game` screenshot shows the editor panel over the live particle effect |

## 3. ImGui integration

### 3.1 `Layer` hook

`engine/core/Layer.hpp` gains `virtual void onImGuiRender() {}` (default no-op).

### 3.2 `GraphicsContext::nativeContext()`

`GraphicsContext` gains `virtual void* nativeContext() const = 0;`;
`SdlOpenGLContext` returns its `SDL_GLContext` (`m_context`).

### 3.3 `ImGuiLayer` (`engine/imgui/ImGuiLayer.{hpp,cpp}`)

```cpp
class ImGuiLayer : public Layer {
 public:
  ImGuiLayer(void* sdlWindow, void* glContext);
  void onAttach() override;   // CreateContext, dark style, InitForOpenGL, GL3 Init
  void onDetach() override;   // GL3/SDL3 Shutdown, DestroyContext
  void begin();               // GL3/SDL3 NewFrame, ImGui::NewFrame
  void end();                 // ImGui::Render, GL3 RenderDrawData
 private:
  void* m_window;
  void* m_glContext;
};
```

`onAttach`: `IMGUI_CHECKVERSION(); ImGui::CreateContext(); ImGui::StyleColorsDark();
ImGui_ImplSDL3_InitForOpenGL((SDL_Window*)m_window, m_glContext);
ImGui_ImplOpenGL3_Init("#version 460");`

### 3.4 `Window::setEventCallback` + gating

`Window` gains `virtual void setEventCallback(std::function<bool(void*)>) = 0;`. In
`SdlWindow::pollEvents`, after handling `SDL_EVENT_QUIT`, call the callback with
`&event`; if it returns `true`, `continue` (skip feeding engine `Input`). The app's
callback forwards to `ImGui_ImplSDL3_ProcessEvent` and returns
`io.WantCaptureMouse` for mouse events / `io.WantCaptureKeyboard` for key events.

### 3.5 `Application` wiring

The app owns `std::unique_ptr<ImGuiLayer> m_imguiLayer`, constructed after the GL
context with `m_window->nativeHandle()` + `m_context->nativeContext()`, `onAttach`ed,
and the window event callback set. In `run()`, after `m_renderer->endFrame()`:
`m_imguiLayer->begin();` → `for (layer) layer->onImGuiRender();` →
`m_imguiLayer->end();` → then screenshot/swap. `~Application` calls
`m_imguiLayer->onDetach()` while the GL context is still valid.

## 4. Particle editor (`particles_game`)

- **New presets** (game-local `EmitParams` factories, added to a named list with the
  v0.20 Burst/Fountain/Smoke): **Jet** (dir up, spread ~0.05, speed 8–11, small,
  gravity down), **Nova** (radial, count ~60, speed 6–10, gold, gravity light),
  **Drizzle** (dir up, spread ~0.4, strong gravity so it arcs and falls).
- **State:** `EmitParams m_editorParams` (editable), `int m_selectedPreset`, a
  `ParticleSystem m_editor` (the live preview emitter at scene center). Default =
  Fountain.
- **`stepSim`:** keep the bouncers + collision bursts; also `m_editor.emit(m_editorParams,
  center, m_rng)` then `update`.
- **`onRender`:** submit the burst + editor particles.
- **`onImGuiRender`:** a "Particle Editor" window — a `Combo` of preset names (loads
  the preset into `m_editorParams` on change) and widgets: `SliderInt` count,
  `SliderFloat` speed min/max, spread, size min/max, life min/max, `SliderFloat3`
  gravity, `ColorEdit3` color, and a live particle count readout.

## 5. Testing

This is an integration/UI milestone: ImGui and the editor are verified by screenshots,
not headless unit tests. The underlying `ParticleSystem`/`Particle` math already has
unit tests (v0.20) and is unchanged.

- **Behavioral:** `particles_game` screenshot shows the ImGui "Particle Editor" panel
  over the live particle scene; `bot_arena`/`arena_game` render unchanged (no
  `onImGuiRender` override).

## 6. Out of scope (later)

ImGui docking/viewports/multi-window, saving/loading presets to disk, gizmos, an
entity inspector, and per-game editor panels for the arena. This milestone is the
ImGui-on-the-layer-stack integration + the particle editor with new presets.

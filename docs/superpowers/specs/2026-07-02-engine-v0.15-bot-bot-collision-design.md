# Engine v0.15 — Bot-Bot Collision & Separation — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Circular (XZ) collision between arena agents with a separation +
elastic-bounce response, resolved O(n²) each fixed step, so agents stop
overlapping. Wall bounce is unchanged.
**Builds on:** v0.14 ECS arena game (merged to `main`). Second gameplay milestone.

## 1. Goal & Motivation

v0.14 agents move and bounce off walls but pass through each other. v0.15 makes
them solid: each agent is a circle in the XZ plane, and each fixed step resolves
pairwise overlaps by pushing the pair apart and (if they are approaching) swapping
the normal component of their velocities so they bounce rather than standoff-push.

## 3. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Shape | Circle in XZ; radius = the agent's `Transform.scale` (cube half-extent); `y` untouched |
| Broadphase | O(n²) over all `(Transform, Velocity)` agents (~49 → ~1176 pairs/step); **no spatial grid** |
| Response | Positional separation (each pushed half the penetration along the XZ normal) + equal-mass elastic swap of normal velocity components **only if approaching** |
| Degenerate | Coincident centers → push along `+X` (no NaN) |
| Player | Included as a solid agent |
| Order | `stepSim`: input → player velocity → integrate all → pairwise collision → wall-bounce all (**wall bounce unchanged, runs last**) |
| Tested core | `resolveAgentPair(...)` pure, header-only, EnTT-free |
| DoD | Agents evenly spaced with no interpenetration; player + walls unchanged |

## 4. The pure helper

`engine/physics/Collision.hpp` gains, beside `resolveWallBounce`:

```cpp
struct AgentPair {
  glm::vec3 posA;
  glm::vec3 velA;
  glm::vec3 posB;
  glm::vec3 velB;
};

// Circle-vs-circle in XZ: separate an overlapping pair and, if they are
// approaching, swap the normal component of their velocities (equal mass).
inline AgentPair resolveAgentPair(glm::vec3 posA, glm::vec3 velA, float rA,
                                  glm::vec3 posB, glm::vec3 velB, float rB) {
  const float dx = posB.x - posA.x;
  const float dz = posB.z - posA.z;
  float dist = std::sqrt(dx * dx + dz * dz);
  const float minDist = rA + rB;
  if (dist >= minDist) return {posA, velA, posB, velB};  // no overlap

  glm::vec3 n;
  if (dist > 1e-4f) {
    n = glm::vec3(dx / dist, 0.0f, dz / dist);
  } else {
    n = glm::vec3(1.0f, 0.0f, 0.0f);  // coincident: pick an axis
    dist = 0.0f;
  }
  const float overlap = minDist - dist;
  posA -= n * (overlap * 0.5f);
  posB += n * (overlap * 0.5f);

  const float vaN = glm::dot(velA, n);
  const float vbN = glm::dot(velB, n);
  if (vaN - vbN > 0.0f) {  // approaching along the normal
    velA += (vbN - vaN) * n;
    velB += (vaN - vbN) * n;
  }
  return {posA, velA, posB, velB};
}
```

## 5. System integration

`ArenaGame::stepSim` is restructured from one integrate+bounce loop into three
passes over the `view<Transform, Velocity>`:

1. **Integrate:** `position += velocity * dt` for all.
2. **Pairwise collision (O(n²)):** collect the entities into a `std::vector`,
   double-loop `i < j`, apply `resolveAgentPair(a.pos, a.vel, a.scale, b.pos, b.vel,
   b.scale)`, and write the four results back.
3. **Wall bounce (unchanged):** `resolveWallBounce` each agent against the arena
   interior — runs last, so any separation that nudged an agent toward a wall is
   still clamped inside.

The input→player-velocity step is unchanged and still runs first. The deterministic
120-step warm-up (v0.14) now also resolves collisions, so the screenshot shows
separated agents.

## 6. Testing

- **Unit (Catch2, no GL, no EnTT):** `resolveAgentPair`:
  - non-overlapping pair → unchanged;
  - overlapping + approaching → separated to just-touching, normal velocities
    swapped (each moves apart);
  - overlapping + already separating → separated positionally, velocities
    unchanged;
  - coincident centers → pushed apart along `+X`, no NaN.
  Existing `resolveWallBounce`/`fixedTimestep` tests stay.
- **Behavioral:** `arena_game` screenshot shows agents spaced out with no
  interpenetration (vs pre-collision clumping); the player and walls are unchanged.

## 7. Out of scope (later milestones)

Spatial grid / broadphase (only needed past hundreds of agents), variable
mass/radius weighting, restitution tuning, stacking, and 3D (Y) collision. This is
the minimal circular separation + elastic bounce.

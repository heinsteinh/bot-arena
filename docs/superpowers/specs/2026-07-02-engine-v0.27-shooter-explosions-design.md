# Engine v0.27 — Shooter Explosions on Kills — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Spawn particle explosions when ships die in `shooter_game` — a tier-scaled
burst at each enemy kill (bullet or ram) and a bigger blast when the player dies. Reuses
the v0.20 `ParticleSystem`; no new engine code.
**Builds on:** v0.26 shooter combat, v0.20 particles, on `main`.

## 1. Goal & Motivation

Kills currently just remove a ship. Explosions give combat impact and reuse the existing
additive-billboard particle system, which glows through bloom.

## 2. Decisions (locked)

| Decision | Choice |
| --- | --- |
| System | One `engine::ParticleSystem m_explosions;` on `ShooterGame`, reusing the existing `m_rng` |
| Enemy kill | Emit a radial warm-orange burst at the enemy position on death (health spent) **and** on ram; **tier-scaled** count/speed/size (grunt small → elite big) |
| Player death | Emit a bigger, brighter blast at the player's death position |
| Presets | Local `enemyExplosion(tier)` / `playerExplosion()` (`EmitParams`) in an anonymous namespace — the particles_game presets are not exported |
| Update | `m_explosions.update(dt)` at the end of `stepSim` |
| Render | In `onRender`, build `std::vector<engine::ParticleInstance>` from `m_explosions.particles()` (`{p.position, p.size, vec4(renderColor(p), 1)}`) and call `renderer.submitParticles(...)` |
| DoD | The screenshot shows glowing bursts at enemy kill sites |

## 3. Particle presets (`ShooterGame.cpp`, anonymous namespace)

```cpp
engine::EmitParams enemyExplosion(int tier) {
  engine::EmitParams p;
  p.count = 24 + tier * 18;                 // 24 / 42 / 60
  p.speedMin = 2.0f; p.speedMax = 4.0f + tier * 1.5f;
  p.direction = {0.0f, 0.0f, 0.0f};         // radial
  p.spread = 1.0f;
  p.color = {1.0f, 0.5f, 0.15f};            // warm orange
  p.sizeMin = 0.12f; p.sizeMax = 0.22f + tier * 0.08f;
  p.lifeMin = 0.4f; p.lifeMax = 0.9f;
  p.gravity = {0.0f, -6.0f, 0.0f};
  return p;
}

engine::EmitParams playerExplosion() {
  engine::EmitParams p;
  p.count = 100;
  p.speedMin = 3.0f; p.speedMax = 9.0f;
  p.direction = {0.0f, 0.0f, 0.0f};
  p.spread = 1.0f;
  p.color = {1.0f, 0.85f, 0.4f};            // bright gold-white
  p.sizeMin = 0.15f; p.sizeMax = 0.4f;
  p.lifeMin = 0.6f; p.lifeMax = 1.2f;
  p.gravity = {0.0f, -4.0f, 0.0f};
  return p;
}
```

(Sizes are tuned up from the particles_game preset because the shooter ships are ~1 unit
and the camera sits at distance 22 — final values may be nudged by screenshot.)

## 4. Emit points (`ShooterGame::stepSim`)

- **Enemy killed** (health `<= 0` in the bullet-hit loop): before destroying, capture the
  enemy tier + position and `m_explosions.emit(enemyExplosion(tier), pos, m_rng)`.
- **Enemy ram** (overlap-with-player loop): same burst at the enemy position.
- **Player death** (HP `<= 0`): `m_explosions.emit(playerExplosion(), playerPos, m_rng)`
  before recentring.
- End of `stepSim`: `m_explosions.update(dt)`.

## 5. Rendering (`ShooterGame::onRender`)

After the bullet loop:

```cpp
std::vector<engine::ParticleInstance> particles;
for (const engine::Particle& p : m_explosions.particles()) {
  particles.push_back({p.position, p.size, glm::vec4(engine::renderColor(p), 1.0f)});
}
renderer.submitParticles(particles);
```

## 6. Testing

Integration on the already-tested `ParticleSystem::emit`/`update` (v0.20) — verified by
screenshot. No new unit test (same pattern as the v0.26 enemy-fire wiring).

- **Behavioral:** the `shooter_game` screenshot shows glowing orange bursts where enemies
  were destroyed. Other games unchanged.

## 7. Out of scope

Muzzle flashes, per-bullet impact sparks, engine/thruster trails, and screen shake.

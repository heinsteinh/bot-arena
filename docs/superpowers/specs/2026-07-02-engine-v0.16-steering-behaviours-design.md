# Engine v0.16 — Steering Behaviours — Design Spec

**Date:** 2026-07-02
**Status:** Approved for planning
**Scope:** Force-based steering for arena bots — `truncate`/`seek`/`flee` pure
helpers, and a seek-the-player behaviour so bots chase the input-driven player.
Collision and wall bounce unchanged.
**Builds on:** v0.15 bot-bot collision (merged to `main`). Third gameplay milestone.

## 1. Goal & Motivation

Bots currently drift at constant velocity, redirected only by collisions and walls.
v0.16 introduces the classic Reynolds **force-based** steering model: each step a bot
computes a steering force, accelerates, clamps to a max speed, then moves. Bots
become agents that actively pursue — demonstrated by a swarm that chases the player.

## 3. Decisions (locked)

| Decision | Choice |
| --- | --- |
| Model | Force-based: `vel += force*dt`, then clamp to `maxSpeed`; bots only. Player stays input-driven. |
| Library | `engine/ai/Steering.hpp` (header-only, EnTT-free, planar XZ): `truncate`, `seek`, `flee` |
| Behaviour | Bots **seek the player** each step (`force = seek(botPos, botVel, playerPos, botMaxSpeed, botMaxForce)`) |
| Params | Bot `maxSpeed 2.5`, `maxForce 8.0`; player speed `3.0` (unchanged) → player can outrun the swarm |
| `flee` | Shipped + tested, unused in the demo (reserved for v0.17) |
| Order | `stepSim`: input → player velocity → **bot steering** → integrate → agent collision → wall-bounce (both unchanged) |
| Tested core | `truncate`, `seek`, `flee` — pure, header-only |
| DoD | Bots cluster around / chase the player (vs the v0.15 even spread) |

## 4. The steering library

`engine/ai/Steering.hpp`:

```cpp
#include <glm/glm.hpp>
namespace engine {

// Clamp a vector's length to `maxLen`.
inline glm::vec3 truncate(glm::vec3 v, float maxLen) {
  const float len = glm::length(v);
  if (len > maxLen && len > 1e-6f) return v * (maxLen / len);
  return v;
}

// Steering force toward `target`: desired = dir*maxSpeed, steering = desired - vel
// (capped at maxForce). Zero at the target.
inline glm::vec3 seek(glm::vec3 pos, glm::vec3 vel, glm::vec3 target,
                      float maxSpeed, float maxForce) {
  const glm::vec3 toTarget = target - pos;
  const float d = glm::length(toTarget);
  if (d < 1e-6f) return glm::vec3(0.0f);
  const glm::vec3 desired = (toTarget / d) * maxSpeed;
  return truncate(desired - vel, maxForce);
}

// Steering force directly away from `target`.
inline glm::vec3 flee(glm::vec3 pos, glm::vec3 vel, glm::vec3 target,
                      float maxSpeed, float maxForce) {
  const glm::vec3 away = pos - target;
  const float d = glm::length(away);
  if (d < 1e-6f) return glm::vec3(0.0f);
  const glm::vec3 desired = (away / d) * maxSpeed;
  return truncate(desired - vel, maxForce);
}

}  // namespace engine
```

Positions/velocities all share `y ≈ 0.3`, so the forces are naturally planar (XZ).

## 5. System integration

`ArenaGame::stepSim` gains a steering pass between the input step and integration:

1. **Input → player velocity** (unchanged).
2. **Read the player position** — query the `Player` entity's `Transform.position`.
3. **Bot steering** — for each `(Transform, Velocity, Bot)`:
   `force = engine::seek(t.position, v.value, playerPos, kBotMaxSpeed,
   kBotMaxForce); v.value += force * dt; v.value = engine::truncate(v.value,
   kBotMaxSpeed);`
4. **Integrate** — `position += velocity * dt` (unchanged).
5. **Agent collision** (unchanged, v0.15).
6. **Wall bounce** (unchanged, v0.14).

Constants in `ArenaGame`: `kBotMaxSpeed = 2.5f`, `kBotMaxForce = 8.0f`. The bots'
random spawn velocity (v0.14) is now steered toward the player over time. The
deterministic 120-step warm-up has bots converge on the stationary (no-input)
player, so the screenshot shows them clustered around the centre.

## 6. Testing

- **Unit (Catch2, no GL, no EnTT):**
  - `truncate` — length below `maxLen` unchanged; above → scaled to `maxLen`.
  - `seek` — from rest toward a target, force points at the target with magnitude
    ≤ `maxForce`; a velocity already at the desired gives ≈ 0; a large opposing
    velocity is capped at `maxForce`; `pos == target` → 0.
  - `flee` — force points away from the target.
- **Behavioral:** `arena_game` shows the bots clustered around / converging on the
  player (a clear "chase") rather than the v0.15 even spread; the player and walls
  are unchanged. Interactive: bots pursue the moving player.

## 7. Out of scope (later milestones)

Wander (per-agent state + RNG), arrive (deceleration near the target), pursue/evade
(predicted position), flocking (align/cohere/separate as forces), and obstacle
avoidance. This milestone is the force model + seek/flee.
